### 2. 這個表格代表甚麼 sapb1

來源：[S026-Q002](<../../原始問答/S026_採購收貨關閉與商品結清科目.md#q2>)；2026-07-27

**問題**

這個表格代表甚麼 sapb1

**歷史回答**

這是 SAP Business One 的「總帳科目決定 → 存貨」設定表。

它的用途是：當使用者操作收貨、出貨、銷售、退貨、存貨重估或生產等交易時，SAP B1 根據這張表，自動決定會計分錄要過到哪些總帳科目。它不是庫存明細表，而是「自動分錄的科目對照設定」。

畫面中的主要欄位：

| 科目類型 | 畫面設定 | 用途 |
|---|---:|---|
| 存貨科目 | 1170 | 記錄庫存資產價值；收貨通常借記、出貨通常貸記 |
| 銷貨成本 | 5121 | 商品銷售出庫時，記錄銷貨成本 |
| 分配科目 | 1550 | 採購收貨暫估／過渡科目，連接採購收貨與應付發票 |
| 差異科目 | 空白 | 主要用於標準成本與實際採購價格的差異 |
| 價格差異科目 | 9114 | 採購基礎單據與後續單據價格不同時使用 |
| 負存貨調整科目 | 空白 | 負庫存補回時，處理成本差異 |
| 存貨餘額－減少科目 | 9134 | 存貨重估造成價值減少時使用 |
| 存貨餘額－增加科目 | 9114 | 存貨重估造成價值增加時使用 |
| 銷售退貨科目 | 4211 | 特定銷售退貨情境下使用 |
| 匯率差異科目 | 9112 | 採購單據使用外幣、匯率不同所產生的差額 |
| 商品結清科目 | 空白 | 結清採購收貨或退貨時，若不再調整庫存價值，用來承接差額 |
| 總帳減少／增加科目 | 空白 | 存貨重估所需的平衡科目 |
| 在製品存貨科目 | 空白 | 生產過程中的在製品價值 |
| 在製品存貨差異科目 | 空白 | 生產投入與完工之間的成本差異 |
| 在製品沖銷損益科目 | 空白 | 特定生產結清或沖銷差異使用 |
| 存貨餘額損益科目 | 空白 | 特定存貨價值差異的損益科目 |
| 費用結清科目 | 空白 | 採購附加費用影響存貨價值時的對應科目 |

簡單例子：

1. 銷售商品出庫，成本為 1,000：

```text
借：銷貨成本 5121       1,000
貸：存貨科目 1170       1,000
```

2. 採購收貨，金額為 1,000：

```text
借：存貨科目 1170       1,000
貸：分配科目 1550       1,000
```

3. 後續建立應付發票時：

```text
借：分配科目 1550       1,000
貸：供應商統馭科目      1,000
```

因此，1550 通常是「收貨未開發票」的暫估科目；其餘額通常代表尚未被應付發票結清的採購收貨。

另外需要注意：

- 畫面選的是 2026 期間，表示這組設定適用於該過帳期間。
- 黃色箭頭可開啟對應的總帳科目資料。
- 這裡通常是預設科目；實際過帳科目可能被倉庫、物料群組、物料主檔或進階科目決定規則覆蓋。
- 空白欄位不一定全部都要填，是否需要取決於存貨計價法、生產功能、負庫存、外幣採購及公司的啟用設定。
- 已經正式使用後不要任意更換科目，否則可能造成存貨稽核報表與總帳不一致。SAP 官方也特別提醒，變更此處可能導致錯誤的存貨交易。

參考：[SAP Business One 10.0－G/L Account Determination: Inventory Tab](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/4506b8ab7d720487e10000000a155369.html)

### 3. 如果我是要把收貨採購單關閉呢

來源：[S026-Q003](<../../原始問答/S026_採購收貨關閉與商品結清科目.md#q3>)；2026-07-27

**問題**

如果我是要把收貨採購單關閉呢

**歷史回答**

如果你要在 SAP B1 把「收貨採購單（Goods Receipt PO）」直接關閉，而不再建立應付發票，畫面中的「商品結清科目」就是會用到的科目。

關閉時，SAP B1 的處理是：

- 不會退回或減少庫存。
- 收貨產生的庫存數量與存貨價值仍然保留。
- 單據狀態改成「已關閉」，之後不能再複製到應付發票。
- 系統會產生結清分錄，把尚未結清的「分配科目」轉到「商品結清科目」。

依你圖片中的設定，假設未開票金額為 10,000，基本分錄概念為：

```text
借：1550 分配科目／暫估應付款       10,000
貸：商品結清科目                  10,000
```

所以你圖片中空白的「商品結清科目」應先設定。如果未設定，關閉收貨採購單時可能會出現「缺少總帳科目」之類的錯誤。

「商品結清科目」建議設定為一個專用損益科目，例如：

```text
未開票採購結清損益
收貨未開票沖銷
GRPO Closing Clearing
```

不要直接使用 1170 存貨科目，因為關閉收貨採購單本身不應再次改變存貨價值。實際應歸類為費用、其他收益或專用結清損益，需由公司的會計政策決定。

特別注意：如果是以下情況，不應使用「關閉」：

- 貨物實際沒有收到或需要退出：建立「採購退貨」。
- 收貨單輸入錯誤，需要整筆撤銷：符合條件時使用「取消」。
- 供應商之後仍會開發票：應保留收貨採購單，再複製到「應付發票」。

「關閉」適合的情況是：貨確實已入庫，但確定不會再收到供應商發票，或只需結清尚未開票的剩餘部分。

另外，SAP 官方說明關閉動作不可逆，執行時系統通常會要求選擇結清分錄的過帳日期。若公司啟用了「採購科目過帳系統」，分錄還可能同時包含採購科目，但核心仍是用「商品結清科目」清掉未結的分配科目。[SAP 官方說明](https://help.sap.com/docs/SAP_BUSINESS_ONE/87e1767ca7584b8f8d60775347637b07/f8b65bce9dcf4ea9a4f71b334e4ff4da.html)

### 5. 找不到相符的記錄 '總帳科目' (OACT) (ODBC -2028) [訊息 131-183] 我要關閉收貨採購 跳出這個

來源：[S026-Q005](<../../原始問答/S026_採購收貨關閉與商品結清科目.md#q5>)；2026-07-27

**問題**

## My request for Codex:
找不到相符的記錄  '總帳科目' (OACT) (ODBC -2028)  [訊息 131-183] 
我要關閉收貨採購 跳出這個

**歷史回答**

這個錯誤表示：SAP B1 關閉收貨採購單、準備產生結清分錄時，找不到所需的總帳科目。

依你提供的畫面，最可能原因就是「商品結清科目」目前空白。

請這樣處理：

1. 進入「管理 → 設定 → 財務 → 總帳科目決定」。
2. 選擇關閉分錄所屬期間，例如 2026。
3. 進入「存貨」頁籤。
4. 在「商品結清科目」選擇一個有效的過帳科目。
5. 按「確定／更新」儲存。
6. 重新開啟收貨採購單，再執行「關閉」。

科目必須符合以下條件：

- 是明細／可過帳科目，不能是標題科目。
- 科目存在於總帳科目表 OACT。
- 科目沒有被鎖定或停用。
- 適用於關閉分錄的過帳日期。
- 若交易包含外幣，建議科目貨幣設定為「所有貨幣」。

關閉時通常會產生類似分錄：

```text
借：1550 分配科目
貸：商品結清科目
```

如果設定「商品結清科目」後仍出現相同錯誤，再檢查：

- 收貨採購單是否包含運費：可能還缺「費用結清科目」。
- 是否啟用了進階總帳科目決定：倉庫、物料群組或物料規則可能指定了已刪除或無效科目。
- 關閉分錄選擇的過帳日期是否屬於另一個期間；例如選到 2025，就要檢查 2025 的科目決定。
- 1550「分配科目」本身是否仍為有效的可過帳科目。
- 若公司啟用了「採購科目過帳系統」，也要確認採購科目、購入商品成本科目及採購餘額科目均有效。

因此，第一步先補上你畫面反白的「商品結清科目」。如果這張收貨採購單有運費，最好也同時補上最下方的「費用結清科目」。

### 6. 通常 商品結清科目

來源：[S026-Q006](<../../原始問答/S026_採購收貨關閉與商品結清科目.md#q6>)；2026-07-27

**問題**

## My request for Codex:
通常 商品結清科目

**歷史回答**

「商品結清科目」通常設定為一個專用的損益類科目，用來承接「收貨後不再開應付發票」的金額。

建議科目名稱：

```text
收貨採購結清差異
收貨未開票結清損益
採購暫估結清差異
GRPO Closing Difference
```

科目性質通常為：

- 損益類明細科目
- 可直接過帳
- 貨幣設定為「所有貨幣」
- 借貸兩方都允許使用

若關閉已收貨但未開票的收貨採購單，通常是：

```text
借：1550 暫估／分配科目
貸：商品結清科目
```

所以這筆金額在多數情況會表現為「其他收入或採購結清利益」。但同一科目也可能因採購退貨結清而出現在借方，因此最好建立獨立的「結清差異」損益科目，而不是直接放入一般營業收入。

不建議使用：

- 1170 存貨科目
- 1550 分配科目
- 5121 銷貨成本
- 9114 存貨盤盈，除非公司會計政策明確規定
- 供應商統馭科目

以你目前的科目編碼結構來看，可以請會計在 91xx 損益類下面新增，例如：

```text
91xx　收貨未開票結清損益
越文：Chênh lệch tất toán hàng nhận chưa hóa đơn
英文：GRPO Closing Difference
```

若金額重大，建議先確認為什麼「已收到貨但不用付款」；正常有供應商發票的收貨採購單，應建立應付發票結清 1550，而不是直接關閉。

### 7. 商品結清科目都常都用甚麼

來源：[S032-Q001](<../../原始問答/S032_查找商品結清科目.md#q1>)；2026-07-29

**問題**

商品結清科目都常都用甚麼

**歷史回答**

如果你是問會計上的「商品帳戶期末結清」，通常結轉到「銷貨成本」科目。

永續盤存制下：

- 賣出商品：借記「銷貨成本」，貸記「商品存貨」
- 期末通常只需依盤點結果調整商品存貨

定期盤存制下，期末會把「期初存貨、進貨、進貨費用、進貨退出及折讓」等科目結轉，計算：

**銷貨成本＝期初存貨＋本期進貨淨額－期末存貨**

最後「銷貨成本」再結轉到「本期損益」。不同教材也可能把「商品存貨」稱為「存貨」或「商品」。

### 8. 不太懂

來源：[S032-Q002](<../../原始問答/S032_查找商品結清科目.md#q2>)；2026-07-29

**問題**

不太懂

**歷史回答**

簡單說：**商品賣掉後，商品的成本通常記在「銷貨成本」科目。**

例如：

- 你用 60 元買進商品 → 記「商品存貨」60 元
- 後來用 100 元賣掉 → 收入記「銷貨收入」100 元
- 原本的成本 60 元 → 轉成「銷貨成本」60 元
- 毛利＝100－60＝40 元

所以：

- 還沒賣掉的商品：放在「商品存貨」
- 已經賣掉的商品成本：放在「銷貨成本」
- 年底要結清損益時：再把「銷貨成本」轉入「本期損益」

### 9. 如果 我是收貨採購單 然後因為要關閉單據 會帶出商品結清科目 但我要怎麼跟財務解釋

來源：[S032-Q003](<../../原始問答/S032_查找商品結清科目.md#q3>)；2026-07-29

**問題**

如果 我是收貨採購單 然後因為要關閉單據 會帶出商品結清科目 但我要怎麼跟財務解釋

**歷史回答**

了解，你說的「商品結清科目」比較像 ERP 裡的**暫時過渡科目**，不是「銷貨成本」。

收貨時，貨已經進來，但廠商發票或應付帳款可能還沒完成，所以系統先把金額放在商品結清科目：

- 收貨：借「商品存貨」、貸「商品結清科目」
- 收到發票：借「商品結清科目」、貸「應付帳款」

兩邊完成後，商品結清科目的金額原則上會互相沖掉，餘額為 0。關閉單據時，系統需要知道未沖完的金額應該放在哪個會計科目。

你可以這樣跟財務說：


這張採購單已完成收貨，現在要關閉單據，系統要求填寫「商品結清科目」。

我的理解是，這個科目是用來暫掛並沖銷「已收貨、尚未完成發票或應付帳款認列」的金額。想請財務協助確認，我們公司應使用哪一個會計科目；如果收貨金額與發票金額有差異，也請協助確認差額應歸入商品結清、進貨價差或其他指定科目。

重點是請財務確認：

- 這個欄位是不是「已收貨未開票／GR-IR」科目
- 關單後若有剩餘金額，要轉入哪個科目
- 是否存在數量或價格差異，避免把真正的差額直接沖掉

### 11. 給我解釋

來源：[S082-Q002](<../../原始問答/S082_項目群組科目與 OCPR 聯絡人.md#q2>)；2026-08-14

**問題**

給我解釋

**歷史回答**

這是 ERP 系統中的「項目群組－設定」畫面，用來指定某一類存貨在進行採購、銷售、入庫、出庫或盤點時，要自動過帳到哪些會計科目。

目前項目群組名稱是「R_零部件」，也就是零部件／原物料類別。

畫面中各欄位的意思：

| 欄位 | 科目代碼 | 用途 |
|---|---:|---|
| 費用科目 | 空白 | 一般費用的過帳科目 |
| 收入科目 | 4121 | 銷售商品時認列國內銷貨收入 |
| 存貨科目 | 1176 | 零部件庫存的資產科目 |
| 銷貨成本 | 5121 | 出貨時認列銷貨成本 |
| 分配科目 | 1550 | 採購收貨與應付發票之間的暫估／過渡科目 |
| 價格差異科目 | 9114 | 採購價格或存貨成本產生差異時使用 |
| 存貨餘額－減少科目 | 9134 | 盤虧、報廢或庫存調減時認列損失 |
| 存貨餘額－增加科目 | 9114 | 盤盈或庫存調增時使用 |
| 銷售退貨科目 | 4211 | 客戶退貨時沖減收入 |
| 匯率差異科目 | 9112 | 外幣交易造成匯兌差異時使用 |
| 商品結清科目 | 9119 | 其他存貨結清或差異收入 |
| 在製品存貨科目 | 1174 | 生產過程中的在製品金額 |
| 在製品存貨差異科目 | 5223 | 在製品實際成本與標準成本的差異 |
| 在製品沖銷益表科目 | 5121 | 完工或結轉時沖銷在製品，轉入銷貨成本 |
| 銷售貸項科目 | 4311 | 銷售折讓或貸項通知單使用 |

簡單來說，系統會依這些設定自動產生會計分錄。例如銷售一項零部件時，通常會同時產生：

1. 認列銷售收入：貸記 `4121`
2. 減少存貨：貸記 `1176`
3. 認列銷貨成本：借記 `5121`

需要注意的是，畫面上有不少欄位仍為空白，例如費用科目、差異科目、負存貨調整科目等。空白是否有問題，要看公司是否會使用相應交易；若會使用而未設定，過帳時可能報錯，或無法建立會計分錄。另外，`9114` 同時用於價格差異和盤盈，應請財務確認是否符合公司的會計科目設計。

### 12. 存貨的收發貨呢

來源：[S082-Q003](<../../原始問答/S082_項目群組科目與 OCPR 聯絡人.md#q3>)；2026-08-14

**問題**

存貨的收發貨呢

**歷史回答**

存貨「收貨／發貨」通常不一定使用畫面上的「收入科目」，而是依交易類型決定過帳科目。

### 存貨收貨

如果是「庫存收貨」，不是向供應商採購入庫，通常分錄是：

- 借：存貨科目 `1176`
- 貸：費用／收入或庫存調整科目（由單據中選擇）

例如盤盈、初始庫存或其他調增，可能使用：

- 借：`1176` 零部件庫存
- 貸：`9114` 存貨盤盈／其他差異

如果是採購收貨，通常是：

- 借：`1176` 存貨
- 貸：`1550` 暫估／分配科目

收到供應商發票後，再沖銷 `1550` 並認列應付帳款。

### 存貨發貨

如果是「庫存發貨」，不是銷售出貨，通常分錄是：

- 借：費用、部門耗用、盤虧或其他指定科目
- 貸：`1176` 存貨科目

例如盤虧或庫存調減：

- 借：`9134` 存貨損失
- 貸：`1176` 零部件庫存

如果是銷售交貨，存貨成本分錄通常為：

- 借：`5121` 銷貨成本
- 貸：`1176` 存貨

另外，銷售收入通常在交貨或發票階段認列：

- 借：應收帳款
- 貸：`4121` 銷售收入

因此，可簡單理解為：

- `1176`：所有存貨收發的核心庫存科目
- `1550`：採購入庫的暫估對方科目
- `5121`：銷售出貨的成本科目
- `9134`：盤虧或其他庫存調減
- `9114`：盤盈或其他庫存調增
- 一般存貨收貨／發貨：對方科目通常由單據上的「總帳科目」決定，不一定完全由這個項目群組畫面控制。

### 13. OCPR 是甚麼

來源：[S082-Q004](<../../原始問答/S082_項目群組科目與 OCPR 聯絡人.md#q4>)；2026-08-14

**問題**

OCPR 是甚麼

**歷史回答**

在 SAP Business One 中，`OCPR` 是「業務夥伴聯絡人」資料表（Contact Persons）。

它儲存客戶、供應商或潛在客戶底下的聯絡人，例如：

- 聯絡人姓名
- 職稱、部門
- 電話、手機、傳真
- 電子郵件
- 地址
- 對應的業務夥伴代碼

常用欄位：

| 欄位 | 說明 |
|---|---|
| `CntctCode` | 聯絡人的唯一識別碼 |
| `CardCode` | 所屬業務夥伴代碼 |
| `Name` | 聯絡人名稱 |
| `FirstName` / `LastName` | 名／姓 |
| `Position` | 職位 |
| `Tel1` / `Tel2` | 電話 |
| `Cellolar` | 手機號碼 |
| `E_MailL` | 電子郵件 |
| `Active` | 是否啟用 |

它通常透過 `CardCode` 與業務夥伴主檔 `OCRD` 關聯：

```sql
SELECT
    T0.CardCode,
    T0.CardName,
    T1.CntctCode,
    T1.Name,
    T1.Tel1,
    T1.Cellolar,
    T1.E_MailL
FROM OCRD T0
LEFT JOIN OCPR T1
    ON T0.CardCode = T1.CardCode;
```

簡單說：

- `OCRD`：客戶／供應商公司主檔
- `OCPR`：該公司底下的個別聯絡人

`OCPR` 與存貨收發貨無關；存貨收貨與發貨會涉及 `OIGN`、`IGN1`、`OIGE`、`IGE1` 等資料表。
