### 1. SAPB1 推薦甚麼辦法做合併財報

來源：[S069-Q001](<../../原始問答/S069_Find SAPB1合併財報方案.md#q1>)；2026-08-12

**問題**

SAPB1 推薦甚麼辦法做合併財報

**歷史回答**

SAP Business One 做合併財報，我通常優先推薦「SAP Business One Intercompany Integration Solution」，但是否適合，要看合併複雜度。

### 建議選型

| 情境 | 建議方案 |
|---|---|
| 2–10 家公司、皆使用 SAP B1、股權結構單純 | **SAP B1 Intercompany Integration Solution** |
| 公司其實只是不同營運據點、共用同一法人 | **SAP B1 Multiple Branches**，不必做真正法定合併 |
| 多國、多幣別、少數股權、權益法、組織重整頻繁 | 導入**專業合併報表／EPM 系統**，由 B1 匯入試算表 |
| 只是每月管理報表，暫時不要求審計軌跡 | SQL/HANA 資料倉儲＋BI 報表，可作為過渡方案 |
| 公司少、預算有限、每季才合併 | Excel/Power Query 可暫用，但不建議長期當正式系統 |

### 首選：Intercompany Integration Solution

SAP 官方方案的做法，是建立獨立的「合併公司資料庫」，把各子公司的會計分錄彙整進來。每一層合併架構通常要建立一個合併公司。

它可以產出：

- 合併試算表
- 合併資產負債表
- 合併損益表
- 合併現金流量表
- 多層級合併
- 科目對應
- 多幣別換算
- 手動或排程合併
- 公司別及集團別查詢

這是 SAP 官方文件描述的標準架構：[Intercompany Integration Solution 使用手冊](https://help.sap.com/doc/012002523100018067042015e/2.0/en-US/IntercompanySolution_2.0_%20User%20Guide_EN.pdf)。

不過要特別確認以下部分是否能完全符合台灣 IFRS 與會計師查核需求：

- 關係人交易及未實現損益沖銷
- 投資與股東權益沖銷
- 商譽
- 非控制權益
- 權益法
- 累積換算調整數
- 合併現金流
- 調整分錄的核准與追蹤

標準方案可處理合併分錄與公司間交易，但複雜沖銷規則通常仍需設定、客製或人工調整。

### Multiple Branches 不等於合併財報

如果只是同一法人下的門市、部門或營業據點，可以使用 SAP B1 的 Multiple Branches，在同一資料庫中依分支記帳及出報表。SAP 官方定位也是用來區分營運單位、交易、庫存與報表。[SAP B1 Multiple Branches 說明](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/50b1c1bc2752475c8fe052c33d15c28f.html)

但不同統編、不同法人需要法定合併時，不應只靠 Multiple Branches。

### 我的實務建議

如果你們是「約 2–10 家關係企業、全部使用 SAP B1、100% 持股居多」，我會選：

**SAP B1 Intercompany Integration Solution＋合併公司帳套＋標準化科目表＋沖銷分錄模板。**

導入順序建議為：

1. 建立集團統一科目表及各公司科目對照。
2. 統一會計期間、幣別和匯率政策。
3. 在客戶、供應商及傳票中標示交易對手公司。
4. 建立合併公司資料庫。
5. 設定資產負債表期末匯率、損益表平均匯率及歷史匯率。
6. 自動產生往來交易沖銷。
7. 對投資、股權、未實現損益及少數股權建立調整流程。
8. 保留「原始數字→換算→調整→沖銷→合併結果」的查核軌跡。

若公司超過約 10–15 家、股權比例複雜，或每月關帳時有大量沖銷，我會直接評估專業合併平台，不建議在 B1 裡做太多客製程式。這類系統讓 B1 負責記帳，合併平台負責股權、匯率、沖銷、工作流程和揭露報表，長期通常比較穩定。
