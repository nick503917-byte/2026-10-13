### 1. SAPB1 存貨稽核報表 功能

來源：[S067-Q001](<../../原始問答/S067_Add SAPB1 inventory audit report.md#q1>)；2026-08-11

**問題**

SAPB1 存貨稽核報表 功能

**歷史回答**

SAP Business One 的「存貨稽核報表（Inventory Audit Report）」主要用來追蹤存貨數量與價值的異動，並核對「存貨模組」和「總帳存貨科目」是否一致。

功能重點：

- 顯示每筆存貨交易造成的數量與金額變化。
- 查看期初數量／金額、交易異動及期末累計數量／價值。
- 依品項、倉庫、品項群組、存貨科目與日期範圍篩選。
- 可按「品項」檢視，或按「會計科目」彙總。
- 可追查來源單據，例如收貨採購單、交貨、庫存收發、盤點過帳、生產及存貨重估。
- 可比較報表中的存貨價值與總帳存貨科目餘額。
- 累計數量或價值為負數時，展開明細會以紅色標示。
- 報表可以列印，並可使用 PLD 調整版面。

操作路徑：

`存貨 → 存貨報表 → 存貨稽核報表`

常見查詢條件：

- 過帳日期或系統日期
- 起訖日期
- 品項編號、品項群組或屬性
- 倉庫
- 存貨科目
- 依品項／依科目彙總
- 顯示期間內無交易但有期初餘額的品項

主要欄位：

| 欄位 | 意義 |
|---|---|
| Quantity | 該筆交易造成的數量增減 |
| Cost | 該筆交易的單位成本 |
| Trans. Value | 過帳至存貨科目的交易價值 |
| Cumulative Qty | 交易後的累計庫存量 |
| Cumulative Value | 交易後的累計存貨價值 |
| Balance from G/L | 總帳存貨科目餘額 |

需要特別注意：

1. 此報表適用於採用「永續盤存制」的公司。
2. 它不會重新計算成本，而是呈現資料庫中已過帳的成本與存貨交易。
3. 如果有人直接對存貨科目做手動分錄，總帳餘額可能與存貨稽核報表不同；應先排除非存貨交易再比較。
4. 過帳日期與系統日期不同的交易可能以藍色顯示，核對歷史期間時尤其要注意。
5. 它不是「實體盤點差異表」；實際庫存盤點與調整應使用「存貨盤點／存貨過帳」功能。
6. 若採序號／批次評價法，應使用「批次及序號存貨稽核報表」，才能追到個別批號或序號。

官方說明：[Inventory Audit Report](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/4522e91373c80108e10000000a114a6b.html)、[Selection Criteria](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/4522e90a73c80108e10000000a114a6b.html)、[與總帳餘額差異原因](https://help.sap.com/docs/SAP_BUSINESS_ONE/87e1767ca7584b8f8d60775347637b07/84adeac14a494349a153dd2fed7d60be.html)。

### 2. 稽核報表的項目成本 跟我 項目主檔看到的成本 有一點不同是正常的嗎

來源：[S067-Q002](<../../原始問答/S067_Add SAPB1 inventory audit report.md#q2>)；2026-08-11

**問題**

## My request:
稽核報表的項目成本 跟我 項目主檔看到的成本 有一點不同是正常的嗎

**歷史回答**

是的，差一點通常是正常的，因為兩邊顯示的成本不一定是同一個時間點與計算口徑。

- 「項目主檔 → 存貨資料」的項目成本，通常是目前最新成本。
- 稽核報表明細的 `Cost`，是該筆存貨交易發生當時使用的成本。
- 稽核報表彙總列的成本，則依累計存貨價值與累計數量計算；不是直接讀取項目主檔的目前成本。SAP 官方也明確說明，報表不能直接使用目前的項目成本回推歷史交易。[SAP 官方說明](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/4522e91373c80108e10000000a114a6b.html)

常見的正常差異原因包括：

1. 查詢截止日不同  
   例如稽核報表做到 7 月 31 日，但項目主檔顯示的是今天的成本；8 月發生過進貨、附加費用或存貨重估，兩者自然不同。

2. 四捨五入  
   畫面可能只顯示 2～6 位小數，但 SAP 內部以更高精度保存。單價看似不同一點，乘上數量後通常仍能對上存貨價值。

3. 依倉庫管理成本  
   若公司勾選「依倉庫管理項目成本」，每個倉庫可能有不同成本。報表若合併多個倉庫，而主檔查看的是某一倉庫，兩者便不能直接比較。[SAP 官方說明](https://help.sap.com/docs/SAP_BUSINESS_ONE/87e1767ca7584b8f8d60775347637b07/58cb74ac9f654cc582dfa80b48fdfe04.html)

4. 評價方法不同  
   移動平均法、標準成本法、FIFO，以及序號／批次評價法的成本意義不同。FIFO 的主檔成本尤其不一定等於某一筆歷史出庫的層別成本。

5. 後續成本調整  
   到岸成本、存貨重估、以收貨採購單為基礎的應付發票價差等，可能只改變存貨價值而沒有數量異動。

建議用這個方式核對：

- 稽核報表截止日設為今天。
- 選擇同一個品項及相同倉庫範圍。
- 若為依倉庫管理成本，勾選「按倉庫分組」。
- 查看最後一列：
  `累計價值 ÷ 累計數量`
- 將結果與項目主檔相同倉庫的成本比較。

若只是小數末位不同，多半是顯示精度／四捨五入；但若差異明顯，或「累計價值 ÷ 累計數量」也對不上，便要檢查負庫存、存貨重估、到岸成本、日期條件及倉庫成本設定。

### 3. 如果我想要 拉出 一個區間的存貨報表 sapb1 可以幫我寫語法嗎

來源：[S090-Q001](<../../原始問答/S090_撰寫 SAP B1 區間存貨報表語法.md#q1>)；2026-08-20

**問題**

如果我想要 拉出 一個區間的存貨報表 sapb1 可以幫我寫語法嗎

**歷史回答**

可以。SAP Business One 可用 `OINM`（存貨異動）拉出指定日期區間的「期初、入庫、出庫、期末」報表。

先提供 SQL Server 版，可直接放進 SAP B1 查詢產生器：

```sql
/* [%0] 起始日期 */
/* [%1] 結束日期 */

SELECT
    T0.ItemCode                         AS '料號',
    MAX(T1.ItemName)                    AS '品名',
    T0.Warehouse                        AS '倉庫',

    SUM(
        CASE WHEN T0.DocDate < [%0]
             THEN T0.InQty - T0.OutQty
             ELSE 0
        END
    )                                   AS '期初數量',

    SUM(
        CASE WHEN T0.DocDate BETWEEN [%0] AND [%1]
             THEN T0.InQty
             ELSE 0
        END
    )                                   AS '期間入庫',

    SUM(
        CASE WHEN T0.DocDate BETWEEN [%0] AND [%1]
             THEN T0.OutQty
             ELSE 0
        END
    )                                   AS '期間出庫',

    SUM(
        CASE WHEN T0.DocDate <= [%1]
             THEN T0.InQty - T0.OutQty
             ELSE 0
        END
    )                                   AS '期末數量',

    SUM(
        CASE WHEN T0.DocDate < [%0]
             THEN T0.TransValue
             ELSE 0
        END
    )                                   AS '期初金額',

    SUM(
        CASE WHEN T0.DocDate BETWEEN [%0] AND [%1]
             THEN T0.TransValue
             ELSE 0
        END
    )                                   AS '期間異動金額',

    SUM(
        CASE WHEN T0.DocDate <= [%1]
             THEN T0.TransValue
             ELSE 0
        END
    )                                   AS '期末金額'

FROM OINM T0
INNER JOIN OITM T1
    ON T0.ItemCode = T1.ItemCode

WHERE T0.DocDate <= [%1]

GROUP BY
    T0.ItemCode,
    T0.Warehouse

HAVING
       SUM(CASE WHEN T0.DocDate < [%0]
                THEN T0.InQty - T0.OutQty ELSE 0 END) <> 0
    OR SUM(CASE WHEN T0.DocDate BETWEEN [%0] AND [%1]
                THEN T0.InQty + T0.OutQty ELSE 0 END) <> 0

ORDER BY
    T0.ItemCode,
    T0.Warehouse;
```

這份報表的計算方式是：

- 期初數量：開始日期以前的累積入庫－出庫
- 期間入庫／出庫：指定日期區間的異動
- 期末數量：結束日期以前的累積入庫－出庫
- 金額：依 SAP B1 的 `TransValue` 計算

若你使用的是 SAP HANA，欄位與語法需要改成雙引號版本。你告訴我以下資訊，我可以幫你寫成正式可用版本：

1. 資料庫是 SQL Server 還是 SAP HANA？
2. 要全部倉庫，還是可選倉庫？
3. 是否需要批號、序號或品項群組？
4. 金額想看「存貨成本異動」還是「期末庫存價值」？

### 4. 這支很好 但可以把期間異動金額 幫我變成 入庫異動金額 出庫異動金額 然後 我的篩選條件只要 我選的過帳日期之前 0731 就是之前都要

來源：[S090-Q002](<../../原始問答/S090_撰寫 SAP B1 區間存貨報表語法.md#q2>)；2026-08-20

**問題**

這支很好 但可以把期間異動金額 幫我變成 入庫異動金額  出庫異動金額 然後 我的篩選條件只要 我選的過帳日期之前 0731 就是之前都要

**歷史回答**

可以，改成只輸入一個「截止過帳日期」。例如輸入 `2026/07/31`，就會統計所有過帳日期小於等於 7/31 的資料。

以下為 SQL Server 版本：

```sql
/* [%0] 截止過帳日期 */

DECLARE @ToDate DATETIME

SET @ToDate = /* T0.DocDate */ '[%0]'

SELECT
    T0.ItemCode                                      AS '料號',
    MAX(T1.ItemName)                                 AS '品名',
    T0.Warehouse                                     AS '倉庫',

    SUM(T0.InQty)                                    AS '累積入庫數量',
    SUM(T0.OutQty)                                   AS '累積出庫數量',
    SUM(T0.InQty - T0.OutQty)                        AS '截止庫存數量',

    SUM(
        CASE
            WHEN T0.InQty > 0 THEN T0.TransValue
            ELSE 0
        END
    )                                                AS '入庫異動金額',

    SUM(
        CASE
            WHEN T0.OutQty > 0 THEN -T0.TransValue
            ELSE 0
        END
    )                                                AS '出庫異動金額',

    SUM(T0.TransValue)                               AS '截止庫存金額'

FROM OINM T0

INNER JOIN OITM T1
    ON T0.ItemCode = T1.ItemCode

WHERE T0.DocDate <= @ToDate

GROUP BY
    T0.ItemCode,
    T0.Warehouse

HAVING
       SUM(T0.InQty - T0.OutQty) <> 0
    OR SUM(T0.TransValue) <> 0

ORDER BY
    T0.ItemCode,
    T0.Warehouse;
```

其中：

- 輸入 `2026/07/31`，條件就是 `DocDate <= 2026/07/31`
- 入庫異動金額：有入庫數量的交易金額
- 出庫異動金額：將 SAP 原本通常為負數的出庫金額轉為正數顯示
- 截止庫存金額：所有入庫與出庫異動金額加總後的庫存價值

如果你希望出庫異動金額維持 SAP 原始的負數，將：

```sql
THEN -T0.TransValue
```

改成：

```sql
THEN T0.TransValue
```

另外要注意，這一版是「截至指定日期的累積報表」，不是單獨統計 7 月份。輸入 7/31 時，會包含系統建帳以來到 7/31 為止的所有存貨異動。

### 5. 我是fms

來源：[S090-Q003](<../../原始問答/S090_撰寫 SAP B1 區間存貨報表語法.md#q3>)；2026-08-20

**問題**

我是fms

**歷史回答**

了解，你指的是 SAP B1 的 FMS（格式化搜尋），那和「查詢產生器報表」不同。

FMS 通常只能把查詢結果回填到一個欄位，不能直接顯示「多料號、多倉庫」的整張存貨報表。因此：

- 若要拉完整存貨報表：應使用「查詢管理員／查詢產生器」。
- 若要在 FMS 畫面依某個過帳日期，自動帶出單一料號或單一倉庫的庫存數量、金額：可以寫，但要引用畫面欄位，例如 `$[$欄位UID.0.DATE]`。

例如單一料號截至畫面過帳日期的庫存數量：

```sql
SELECT SUM(T0.InQty - T0.OutQty)
FROM OINM T0
WHERE T0.ItemCode = $[$料號欄位UID.0.0]
  AND T0.DocDate <= $[$過帳日期欄位UID.0.DATE]
```

但我需要知道 FMS 掛在哪個 SAP B1 畫面，以及：

- 過帳日期欄位的 UID
- 料號欄位的 UID
- 要回填的是數量、入庫金額、出庫金額，還是庫存金額

如果你是在維熹 FMS 系統中執行「SAP B1 報表 SQL」，而不是 SAP 的「格式化搜尋」，也請告訴我；那我會把上一支改成 FMS 報表參數格式。

### 6. 跟 剛剛第一個一樣 沒辦法用declare

來源：[S090-Q004](<../../原始問答/S090_撰寫 SAP B1 區間存貨報表語法.md#q4>)；2026-08-20

**問題**

跟 剛剛第一個一樣 沒辦法用declare

**歷史回答**

了解，沿用第一支 SAP B1 查詢格式，不使用 `DECLARE`，只保留一個截止過帳日期參數 `[%0]`。

```sql
/* [%0] 截止過帳日期 */

SELECT
    T0.ItemCode                              AS '料號',
    MAX(T1.ItemName)                         AS '品名',
    T0.Warehouse                             AS '倉庫',

    SUM(T0.InQty)                            AS '入庫數量',
    SUM(T0.OutQty)                           AS '出庫數量',
    SUM(T0.InQty - T0.OutQty)                AS '截止庫存數量',

    SUM(
        CASE
            WHEN T0.InQty > 0
            THEN T0.TransValue
            ELSE 0
        END
    )                                        AS '入庫異動金額',

    SUM(
        CASE
            WHEN T0.OutQty > 0
            THEN -T0.TransValue
            ELSE 0
        END
    )                                        AS '出庫異動金額',

    SUM(T0.TransValue)                       AS '截止庫存金額'

FROM OINM T0

INNER JOIN OITM T1
    ON T0.ItemCode = T1.ItemCode

WHERE T0.DocDate <= [%0]

GROUP BY
    T0.ItemCode,
    T0.Warehouse

HAVING
       SUM(T0.InQty - T0.OutQty) <> 0
    OR SUM(T0.TransValue) <> 0

ORDER BY
    T0.ItemCode,
    T0.Warehouse;
```

執行時只會要求輸入一個日期。例如輸入 `2026/07/31`，就會抓取：

```sql
T0.DocDate <= 2026/07/31
```

也就是包含 7/31 當天，以及 7/31 以前的所有存貨異動。

目前「出庫異動金額」以正數呈現；如果希望保留 SAP 原始負數，把：

```sql
THEN -T0.TransValue
```

改成：

```sql
THEN T0.TransValue
```

### 7. ORDER BY T0.ItemCode, T0.Warehouse; 這是甚麼意思

來源：[S090-Q005](<../../原始問答/S090_撰寫 SAP B1 區間存貨報表語法.md#q5>)；2026-08-20

**問題**

ORDER BY
    T0.ItemCode,
    T0.Warehouse; 這是甚麼意思

**歷史回答**

這段只是設定查詢結果的排列順序：

```sql
ORDER BY
    T0.ItemCode,
    T0.Warehouse;
```

意思是：

1. 先依「料號」`ItemCode` 排序。
2. 同一料號有多個倉庫時，再依「倉庫代碼」`Warehouse` 排序。

例如：

```text
料號    倉庫
A001    01
A001    02
A002    01
A002    03
```

它不會影響庫存數量或金額計算，只會影響顯示順序。

也可以改成用中文欄位名稱排序：

```sql
ORDER BY
    '料號',
    '倉庫';
```

但 SQL Server 可能把單引號內容視為固定文字，因此建議保留原本寫法。若不在意排序，整段 `ORDER BY` 可以直接刪除。

### 8. 幫我找 我有做過庫存異動的查詢報表嗎

來源：[S119-Q001](<../../原始問答/S119_尋找庫存異動查詢報表.md#q1>)；2026-08-28

**問題**
