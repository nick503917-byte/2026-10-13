### 11. SAPB1 庫存調撥的卡控： 我想要寫SP，關於庫存調撥單我想要 需要必填參考文件。

來源：[S072-Q001](<../../原始問答/S072_新增庫存調撥參考文件卡控.md#q1>)；2026-08-13

**問題**

SAPB1 庫存調撥的卡控：

我想要寫SP，關於庫存調撥單我想要 需要必填參考文件。

**歷史回答**

可以。這類卡控通常寫在 SAP B1 的 `SBO_SP_TransactionNotification`，於「庫存調撥單」新增或更新時，檢查「參考文件」是否空白，空白就禁止儲存。

不過要先確認兩項資料，才能寫出可直接使用的 SP：

1. SAP B1 資料庫是 **SQL Server** 還是 **SAP HANA**？
2. 「參考文件」是哪個欄位？
   - 系統欄位，例如 `OWTR.Ref2`
   - 自訂欄位，例如 `OWTR.U_RefDoc`

假設是 **SQL Server**，而且「參考文件」是表頭自訂欄位 `U_RefDoc`，可在 `SBO_SP_TransactionNotification` 中加入：

```sql
/* 庫存調撥單：參考文件必填 */
IF @object_type = '67'
   AND @transaction_type IN ('A', 'U')
BEGIN
    IF EXISTS
    (
        SELECT 1
        FROM OWTR T0
        WHERE T0.DocEntry = TRY_CONVERT(INT, @list_of_cols_val_tab_del)
          AND ISNULL(LTRIM(RTRIM(T0.U_RefDoc)), '') = ''
    )
    BEGIN
        SET @error = -5001
        SET @error_message = N'庫存調撥單的「參考文件」為必填，請輸入後再儲存。'
    END
END
```

重點：

- 庫存調撥單的 `object_type` 是 `67`。
- `A` 代表新增，`U` 代表更新。
- 請將 `U_RefDoc` 換成實際欄位名稱。
- 這段應放在 SP 最後的 `SELECT @error, @error_message` 之前。
- 修改正式環境前，建議先備份原本的 `SBO_SP_TransactionNotification`。

請告訴我「SQL Server 或 HANA」以及實際欄位名稱，我就能替你整理成可直接貼入的完整版本。

### 12. 參考文件 WTR21

來源：[S072-Q002](<../../原始問答/S072_新增庫存調撥參考文件卡控.md#q2>)；2026-08-13

**問題**

參考文件 WTR21

**歷史回答**

了解，`WTR21` 是「庫存調撥－參考文件資訊」。若要求庫存調撥單至少輸入一筆參考文件，可在 SQL Server 的 `SBO_SP_TransactionNotification` 中加入：

```sql
/* 庫存調撥單：參考文件至少必填一筆 */
IF @object_type = '67'
   AND @transaction_type IN ('A', 'U')
BEGIN
    IF NOT EXISTS
    (
        SELECT 1
        FROM WTR21 T0
        WHERE T0.DocEntry = CONVERT(INT, @list_of_cols_val_tab_del)
          AND T0.ObjectType = '67'
    )
    BEGIN
        SET @error = -5001
        SET @error_message = N'庫存調撥單的「參考文件」為必填，請至少新增一筆參考文件。'
    END
END
```

請放在 SP 最後這段之前：

```sql
SELECT @error, @error_message
```

說明：

- `67`：庫存調撥單物件類型。
- `WTR21.DocEntry`：對應 `OWTR.DocEntry`。
- `A`：新增時卡控。
- `U`：更新時也卡控，可防止使用者刪除全部參考文件。
- `NOT EXISTS`：找不到任何參考文件時禁止儲存。

若想確認參考文件不是空白資料，可以加強為：

```sql
IF @object_type = '67'
   AND @transaction_type IN ('A', 'U')
BEGIN
    IF NOT EXISTS
    (
        SELECT 1
        FROM WTR21 T0
        WHERE T0.DocEntry = CONVERT(INT, @list_of_cols_val_tab_del)
          AND T0.ObjectType = '67'
          AND
          (
              /* 系統文件 */
              (
                  T0.RefType = 'S'
                  AND T0.RefDocEntr IS NOT NULL
                  AND T0.RefObjType IS NOT NULL
              )
              OR
              /* 外部文件 */
              (
                  T0.RefType = 'E'
                  AND ISNULL(LTRIM(RTRIM(T0.ExtDocNum)), '') <> ''
              )
          )
    )
    BEGIN
        SET @error = -5001
        SET @error_message = N'庫存調撥單的「參考文件」為必填，請輸入有效的系統或外部參考文件。'
    END
END
```

建議採用第二版，因為它不只要求 `WTR21` 有資料，也會檢查參考內容是否有效。`WTR21` 確實是庫存調撥的 Document Reference Information 表，而庫存調撥物件代碼為 `67`。[SAP Business One SDK 表格索引](https://help.sap.com/doc/089315d8d0f8475a9fc84fb919b501a3/10.0/en-US/SDKHelp/index.html)

### 13. 我要加條件 OWTR Series = 111 的時候，我才要卡這個卡控

來源：[S072-Q003](<../../原始問答/S072_新增庫存調撥參考文件卡控.md#q3>)；2026-08-13

**問題**

我要加條件 OWTR Series = 111 的時候，我才要卡這個卡控

**歷史回答**

可以，在卡控條件中加入 `OWTR.Series = 111`。以下是 SQL Server 版本：

```sql
/* 庫存調撥單：Series = 111 時，參考文件至少必填一筆 */
IF @object_type = '67'
   AND @transaction_type IN ('A', 'U')
BEGIN
    IF EXISTS
    (
        SELECT 1
        FROM OWTR T0
        WHERE T0.DocEntry = TRY_CONVERT(INT, @list_of_cols_val_tab_del)
          AND T0.Series = 111
          AND NOT EXISTS
          (
              SELECT 1
              FROM WTR21 T1
              WHERE T1.DocEntry = T0.DocEntry
                AND T1.ObjectType = '67'
          )
    )
    BEGIN
        SET @error = -5001
        SET @error_message =
            N'此庫存調撥單的「參考文件」為必填，請至少新增一筆參考文件。'
    END
END
```

請放在 `SBO_SP_TransactionNotification` 最後這段之前：

```sql
SELECT @error, @error_message
```

邏輯如下：

- 只檢查庫存調撥單：`@object_type = '67'`
- 新增、更新時檢查：`A`、`U`
- 只有 `OWTR.Series = 111` 才啟用卡控
- `WTR21` 沒有對應的參考文件時禁止儲存

若要同時確認參考文件內容有效，可把內層的 `NOT EXISTS` 改成：

```sql
AND NOT EXISTS
(
    SELECT 1
    FROM WTR21 T1
    WHERE T1.DocEntry = T0.DocEntry
      AND T1.ObjectType = '67'
      AND
      (
          (
              T1.RefType = 'S'
              AND T1.RefDocEntr IS NOT NULL
              AND T1.RefObjType IS NOT NULL
          )
          OR
          (
              T1.RefType = 'E'
              AND ISNULL(LTRIM(RTRIM(T1.ExtDocNum)), '') <> ''
          )
      )
)
```

如果需求只是「至少存在一筆參考文件」，使用第一段即可。

### 14. 有點亂 幫我寫一個完整的 你剛剛推薦給我的第二段

來源：[S072-Q004](<../../原始問答/S072_新增庫存調撥參考文件卡控.md#q4>)；2026-08-13

**問題**

有點亂 幫我寫一個完整的 你剛剛推薦給我的第二段

**歷史回答**

以下是完整的 SQL Server 卡控，可直接放入 `SBO_SP_TransactionNotification` 的 `SELECT @error, @error_message` 之前：

```sql
/* 
   庫存調撥單卡控：
   當 Series = 111 時，必須填寫有效的參考文件
*/
IF @object_type = '67'
   AND @transaction_type IN ('A', 'U')
BEGIN
    IF EXISTS
    (
        SELECT 1
        FROM OWTR T0
        WHERE T0.DocEntry = TRY_CONVERT(INT, @list_of_cols_val_tab_del)
          AND T0.Series = 111
          AND NOT EXISTS
          (
              SELECT 1
              FROM WTR21 T1
              WHERE T1.DocEntry = T0.DocEntry
                AND T1.ObjectType = '67'
                AND
                (
                    /* 系統文件 */
                    (
                        T1.RefType = 'S'
                        AND T1.RefDocEntr IS NOT NULL
                        AND T1.RefObjType IS NOT NULL
                    )

                    OR

                    /* 外部文件 */
                    (
                        T1.RefType = 'E'
                        AND ISNULL(
                                LTRIM(RTRIM(T1.ExtDocNum)),
                                ''
                            ) <> ''
                    )
                )
          )
    )
    BEGIN
        SET @error = -5001
        SET @error_message =
            N'此庫存調撥單的「參考文件」為必填，請輸入有效的系統或外部參考文件。'
    END
END
```

完整邏輯：

- 只檢查庫存調撥單（物件類型 `67`）。
- 新增或更新時執行。
- 只有 `OWTR.Series = 111` 才進行卡控。
- 系統參考文件：`RefType = 'S'`，且參考文件內碼與物件類型不可為空。
- 外部參考文件：`RefType = 'E'`，且外部文件號碼不可空白。
- 只要有一筆有效的系統或外部參考文件，就允許儲存。

### 16. 如果我連草稿都要做卡控的話

來源：[S072-Q006](<../../原始問答/S072_新增庫存調撥參考文件卡控.md#q6>)；2026-08-13

**問題**

如果我連草稿都要做卡控的話

**歷史回答**

可以，草稿需要另外檢查：

- 草稿表頭：`ODRF`
- 草稿參考文件：`DRF21`
- 草稿物件類型：`112`
- `ODRF.ObjType = '67'`：表示這張草稿是庫存調撥單

以下為測試序列 `Series = 21` 的完整 SQL Server 版本，可同時卡控正式單據與草稿：

```sql
/*
    庫存調撥單與草稿卡控：
    當 Series = 21 時，必須填寫有效的參考文件
*/

/* 一、正式庫存調撥單 */
IF @object_type = '67'
   AND @transaction_type IN ('A', 'U')
BEGIN
    IF EXISTS
    (
        SELECT 1
        FROM OWTR T0
        WHERE T0.DocEntry =
              TRY_CONVERT(INT, @list_of_cols_val_tab_del)
          AND T0.Series = 21
          AND NOT EXISTS
          (
              SELECT 1
              FROM WTR21 T1
              WHERE T1.DocEntry = T0.DocEntry
                AND T1.ObjectType = '67'
                AND
                (
                    /* 系統參考文件 */
                    (
                        T1.RefType = 'S'
                        AND T1.RefDocEntr IS NOT NULL
                        AND T1.RefObjType IS NOT NULL
                    )
                    OR
                    /* 外部參考文件 */
                    (
                        T1.RefType = 'E'
                        AND ISNULL(
                            LTRIM(RTRIM(T1.ExtDocNum)),
                            ''
                        ) <> ''
                    )
                )
          )
    )
    BEGIN
        SET @error = -5001
        SET @error_message =
            N'庫存調撥單的「參考文件」為必填，請輸入有效的系統或外部參考文件。'
    END
END


/* 二、庫存調撥草稿 */
IF @object_type = '112'
   AND @transaction_type IN ('A', 'U')
BEGIN
    IF EXISTS
    (
        SELECT 1
        FROM ODRF T0
        WHERE T0.DocEntry =
              TRY_CONVERT(INT, @list_of_cols_val_tab_del)
          AND T0.ObjType = '67'
          AND T0.Series = 21
          AND NOT EXISTS
          (
              SELECT 1
              FROM DRF21 T1
              WHERE T1.DocEntry = T0.DocEntry
                AND T1.ObjectType = '112'
                AND
                (
                    /* 系統參考文件 */
                    (
                        T1.RefType = 'S'
                        AND T1.RefDocEntr IS NOT NULL
                        AND T1.RefObjType IS NOT NULL
                    )
                    OR
                    /* 外部參考文件 */
                    (
                        T1.RefType = 'E'
                        AND ISNULL(
                            LTRIM(RTRIM(T1.ExtDocNum)),
                            ''
                        ) <> ''
                    )
                )
          )
    )
    BEGIN
        SET @error = -5002
        SET @error_message =
            N'庫存調撥草稿的「參考文件」為必填，請輸入有效的系統或外部參考文件。'
    END
END
```

請放在 `SBO_SP_TransactionNotification` 最後的以下程式碼之前：

```sql
SELECT @error, @error_message
```

這樣會產生以下結果：

- 正式庫存調撥單，序列為 `21`：必填參考文件。
- 庫存調撥草稿，序列為 `21`：儲存草稿時也必填。
- 其他序列：不進行此項卡控。
- 其他種類的草稿：不受影響。

要改正式環境時，把兩處：

```sql
T0.Series = 21
```

都改成：

```sql
T0.Series = 111
```
