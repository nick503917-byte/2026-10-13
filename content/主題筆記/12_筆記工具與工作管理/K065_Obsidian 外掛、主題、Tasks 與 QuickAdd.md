有一個筆記的程式 是紫色的

**歷史回答**

你說的很可能是 **Microsoft OneNote**，它的圖示是紫色的筆記本。

### 3. 對 可以幫我整理出來 甚麼好用的外掛套件嗎? 我的職業是 sap相關的工作

來源：[S010-Q003](<../../原始問答/S010_尋找紫色筆記程式.md#q3>)；2026-07-22

**問題**

對 可以幫我整理出來 甚麼好用的外掛套件嗎?
我的職業是 sap相關的工作

**歷史回答**

很適合用 **Obsidian**。SAP 的知識很零散：交易碼、設定路徑、錯誤訊息、功能規格、會議紀錄、專案待辦，都能慢慢連成可搜尋的個人知識庫。

我建議先裝這 6 個，已經很夠用：

1. [Dataview](https://community.obsidian.md/plugins/dataview)  
   把筆記當資料庫查詢。可做「所有 FI/CO 交易碼」、「未結案問題」、「本週專案待辦」清單。

2. [Tasks](https://community.obsidian.md/plugins/obsidian-tasks-plugin)  
   集中各筆記中的待辦，支援截止日、重複任務與篩選。很適合追 SAP issue、測試缺陷與待確認事項。

3. [Templater](https://community.obsidian.md/plugins/templater-obsidian)  
   自動帶入日期、專案名、系統環境等欄位。注意：它可執行 JavaScript 與系統指令，模板只用自己寫的或可信來源。

4. [QuickAdd](https://community.obsidian.md/plugins/quickadd)  
   設快捷鍵快速建立「交易碼筆記」、「錯誤處理紀錄」、「會議紀錄」。比每次手動建檔快很多。

5. [Excalidraw](https://community.obsidian.md/plugins/obsidian-excalidraw-plugin)  
   畫流程圖：例如 PO → GR → Invoice、介面資料流、權限流程或 SAP 模組關聯。

6. [Git](https://community.obsidian.md/plugins/obsidian-git)  
   自動備份與版本紀錄，適合把自己的筆記放在私人 Git repository。手機端穩定性較差，建議主要在電腦使用。

先不用急著裝太多。Obsidian 內建的 **Properties、Bases、Canvas、Daily notes、Templates** 也非常值得先開啟。

我會這樣建立 SAP 筆記結構：

```text
SAP/
  Transactions/       ← T-code，如 ME21N、SE16N、SM37
  Modules/            ← FI、CO、MM、SD、PP…
  Projects/           ← 專案、需求、會議、待辦
  Errors/             ← 錯誤碼、原因、解法
  Interfaces/         ← IDoc、API、RFC、Batch Job
  Config/             ← SPRO 設定與設定路徑
  Templates/
```

交易碼筆記可以用這個模板：

```markdown
---
type: tcode
module: MM
system: S4
status: active
tags: [sap, mm, tcode]
---

# ME21N — 建立採購單

- 用途：
- 使用角色／權限：
- 前置條件：
- 常用欄位：
- 設定或相關 T-code：
- 常見錯誤：
- 相關文件：
- 最後驗證：2026-07-22
```

小提醒：不要把公司機密、正式帳密、客戶個資或可識別的正式系統資料直接同步到第三方雲端或公開 Git。  

如果你告訴我你主要做哪個模組（例如 MM／FI／SD／ABAP／Basis），我可以再幫你做一套更貼近工作的資料夾、標籤與模板。

### 4. OBSIDIAN 有畫面的模組嗎 好看的

來源：[S114-Q001](<../../原始問答/S114_尋找好看的 Obsidian 模組.md#q1>)；2026-08-27

**問題**

OBSIDIAN　有畫面的模組嗎　好看的

**歷史回答**

有，而且可以弄得很像漂亮的個人管理系統，不只是文字筆記。

我最推薦這幾個：

- **Dashboard**：中文介面的視覺化首頁，有待辦事項、筆記統計、年度活動格、最近筆記，甚至有 3D 星系知識圖。整體完成度很高，但目前算較新的外掛。[外掛介紹](https://community.obsidian.md/plugins/aurora-dashboard)
- **Startpage**：比較簡潔穩重的卡片式首頁，顯示釘選筆記、最近編輯、搜尋與資料庫統計。[外掛介紹](https://community.obsidian.md/plugins/start-page)
- **Extended Graph**：把關聯圖譜大幅美化，可以加入圖片節點、不同形狀、顏色、篩選和固定節點；只支援桌面版。[外掛介紹](https://community.obsidian.md/plugins/extended-graph)
- **Fancy Charts**：直接把 Markdown 表格變成漂亮的長條圖、圓餅圖、折線圖、熱力圖、桑基圖，操作也比較親民。[外掛介紹](https://community.obsidian.md/plugins/fancy-charts)
- **Charts View**：功能更完整，適合做工作進度、工時、費用、設備統計等儀表板，可接 CSV 或 Dataview。[外掛介紹](https://community.obsidian.md/plugins/obsidian-chartsview-plugin)
- **Charts for Bases**：如果你已經使用 Obsidian 的 Bases 資料庫功能，這個可以直接做互動式長條圖及折線圖。[外掛介紹](https://community.obsidian.md/plugins/charts)

外觀主題則推薦：

- **Border**：乾淨、有卡片感、可調整程度非常高，搭配 Style Settings 很漂亮。[預覽與設定](https://github.com/Akifyss/obsidian-border)
- **AnuPpuccin**：色彩比較豐富，有彩虹資料夾、Catppuccin 配色和多種漂亮的待辦圖示。[預覽與設定](https://github.com/AnubisNekhet/AnuPpuccin)

如果是你這個 **FMS／工作管理用途**，我的首選組合會是：

**Border 主題＋Dashboard 首頁＋Dataview＋Charts View＋Calendar**

這樣可以做成有：

- 今日待辦
- 工單狀態
- 專案進度
- 設備／客戶統計
- 日曆
- 最近異動
- 圖表儀表板

安裝位置是：`設定 → 第三方外掛 → 瀏覽`，搜尋上述英文名稱即可。主題則在 `設定 → 外觀 → 主題 → 管理`。

### 5. Dataview 這是甚麼

來源：[S114-Q002](<../../原始問答/S114_尋找好看的 Obsidian 模組.md#q2>)；2026-08-27

**問題**

## My request:
Dataview 這是甚麼

**歷史回答**

**Dataview 是 Obsidian 的資料查詢外掛**。

簡單說，它能把散落在不同筆記裡的資料，自動整理成：

- 表格
- 清單
- 待辦事項
- 分組統計
- 儀表板資料

例如每張工單筆記都寫：

```yaml
---
客戶: 維熹
狀態: 進行中
負責人: 王先生
期限: 2026-08-30
---
```

Dataview 就能自動產生工單總表：

```dataview
TABLE 客戶, 狀態, 負責人, 期限
FROM "工單"
SORT 期限 ASC
```

結果會顯示成類似這樣：

| 工單 | 客戶 | 狀態 | 負責人 | 期限 |
|---|---|---|---|---|
| 空調維修 | 維熹 | 進行中 | 王先生 | 2026-08-30 |
| 消防檢查 | A公司 | 已完成 | 李先生 | 2026-09-02 |

它的重點是：**原始資料仍然是普通 Markdown 筆記，Dataview 只是即時查詢及呈現，不會把資料鎖在特殊資料庫裡。**

很適合你的 FMS 用途，例如做：

- 尚未完成的工單
- 本週到期項目
- 各客戶設備清單
- 各專案執行進度
- 依負責人整理的工作
- 保養與合約到期提醒

不過 Dataview 本身偏向「整理資料」，畫面不算華麗；通常會再搭配 **Border 主題、Dashboard 或圖表外掛**，做成好看的首頁儀表板。

### 6. Dataview 怎麼用

來源：[S114-Q003](<../../原始問答/S114_尋找好看的 Obsidian 模組.md#q3>)；2026-08-27

**問題**

## My request:
Dataview  怎麼用

**歷史回答**

Dataview 的使用邏輯只有兩步：

1. 在每篇筆記填入「屬性」
2. 在總表筆記寫 Dataview 查詢

## 1. 安裝 Dataview

在 Obsidian：

`設定 → 第三方外掛 → 關閉安全模式／開啟社群外掛 → 瀏覽`

搜尋 **Dataview**，依序按：

`安裝 → 啟用`

## 2. 建立工單資料夾

建立一個資料夾：

```text
工單
```

在裡面建立幾篇筆記，例如：

```text
工單/
├─ 空調異常.md
├─ 消防設備檢查.md
└─ 電梯定期保養.md
```

## 3. 填寫工單屬性

打開「空調異常.md」，在筆記最上方加入：

```yaml
---
customer: 維熹
status: 進行中
assignee: 王先生
priority: 高
due: 2026-08-30
---
```

下面可以繼續寫一般內容：

```markdown
# 空調異常

三樓會議室冷氣無法啟動。

## 處理事項

- [x] 確認異常
- [ ] 聯絡廠商
- [ ] 完成維修
```

其他工單也使用相同欄位，只需修改內容。

> 新版 Obsidian 也可以透過筆記上方的「新增屬性」按鈕填寫，不一定要手動輸入 YAML。

## 4. 建立工單總表

新增一篇「工單總表.md」，貼入：

````markdown
```dataview
TABLE
  customer AS "客戶",
  status AS "狀態",
  assignee AS "負責人",
  priority AS "優先程度",
  due AS "期限"
FROM "工單"
SORT due ASC
```
````

切換成「閱讀模式」後，就會自動顯示工單表格。

## 常用查詢

只顯示尚未完成的工單：

````markdown
```dataview
TABLE customer AS "客戶", assignee AS "負責人", due AS "期限"
FROM "工單"
WHERE status != "已完成"
SORT due ASC
```
````

只顯示高優先工單：

````markdown
```dataview
TABLE customer AS "客戶", status AS "狀態", due AS "期限"
FROM "工單"
WHERE priority = "高"
SORT due ASC
```
````

顯示資料夾內所有未完成待辦：

````markdown
```dataview
TASK
FROM "工單"
WHERE !completed
```
````

顯示七天內到期的工單：

````markdown
```dataview
TABLE customer AS "客戶", status AS "狀態", due AS "期限"
FROM "工單"
WHERE due >= date(today)
  AND due <= date(today) + dur(7 days)
  AND status != "已完成"
SORT due ASC
```
````

## 指令意思

- `TABLE`：產生表格
- `FROM "工單"`：從工單資料夾抓資料
- `WHERE`：設定篩選條件
- `SORT due ASC`：期限由近到遠排列
- `AS "客戶"`：把欄位標題顯示成中文
- `TASK`：收集筆記中的核取方塊待辦

Dataview 官方也支援 `LIST`、`TABLE`、`TASK`、`CALENDAR` 四種主要查詢形式。[官方說明](https://github.com/blacksmithgu/obsidian-dataview/blob/master/docs/docs/index.md)

建議欄位名稱先使用英文，例如 `status`、`due`，顯示時再透過 `AS "狀態"` 改成中文，日後撰寫查詢會比較穩定。

### 7. 可以再推薦幾個外掛 讓我畫面好看一點嗎

來源：[S114-Q004](<../../原始問答/S114_尋找好看的 Obsidian 模組.md#q4>)；2026-08-27

**問題**

## My request:
可以再推薦幾個外掛 讓我畫面好看一點嗎

**歷史回答**

可以。你現在既然準備使用 **Border 主題**，我推薦以下幾個，效果比較明顯。

## 最推薦安裝

### 1. Style Settings

這個幾乎是 Border 的必裝搭檔，可以直接調整：

- 背景及強調色
- 卡片式版面
- 圓角、陰影及透明度
- 標題和文字顏色
- 側邊欄自動隱藏
- 新分頁背景
- Callout 樣式

安裝後到：

`設定 → Style Settings → Border`

Border 官方也特別建議搭配這個外掛。[外掛介紹](https://community.obsidian.md/plugins/obsidian-style-settings)

### 2. Iconic

可以替資料夾、檔案、標籤、書籤和頁籤加上圖示及顏色，例如：

```text
🏠 首頁
📋 工單
🏢 客戶
🛠️ 設備
📅 保養計畫
📊 報表
📦 附件
```

操作方式通常是對資料夾或檔案按右鍵，更換圖示。它提供大量 Lucide 圖示和 Emoji。[外掛介紹](https://community.obsidian.md/plugins/iconic)

> 不太建議現在新裝 Iconize，因為其外掛頁面已標示停止維護；改裝較新的 Iconic。

### 3. Homepage Blocks

可以做成真正的視覺化首頁，而且不用自己寫複雜程式：

- 問候語、日期和時鐘
- 常用功能按鈕
- 最近開啟的筆記
- 圖片區塊
- 快速搜尋
- 番茄鐘
- 引用與書籤
- 嵌入 Dataview 工單總表
- 卡片拖曳及調整大小

還能調整每張卡片的漸層、透明度、陰影和毛玻璃效果。[外掛介紹](https://community.obsidian.md/plugins/homepage-blocks)

### 4. Cards View

把筆記從普通檔案清單變成卡片牆，可以：

- 顯示筆記預覽
- 按標籤篩選
- 釘選重要筆記
- 按建立或修改時間排列

很適合瀏覽「客戶、設備、專案、知識文件」。[外掛介紹](https://community.obsidian.md/plugins/cards-view)

### 5. Banners

在每篇筆記上方放置橫幅圖片和 Emoji，例如客戶頁面放大樓照片、設備頁面放設備照片。[外掛介紹](https://community.obsidian.md/plugins/obsidian-banners)

如果希望在編輯模式和閱讀模式都能顯示，也可以選比較新的 [Banner Images](https://community.obsidian.md/plugins/banner-images)。

### 6. Explorer

把資料夾內容顯示成漂亮的卡片或清單，包含：

- 筆記預覽
- 搜尋及排序
- 釘選常用筆記
- 圖片及標籤
- 拖曳整理
- 資料夾首頁

它很適合把「客戶」或「專案」資料夾變成類似 Notion 的圖庫頁面。[外掛介紹](https://community.obsidian.md/plugins/explorer)

### 7. Gallery View

如果工單或設備會附很多現場照片，這個可以把附件顯示成：

- 縮圖網格
- 瀑布流
- 輪播
- 點擊放大

支援 Vault 內的圖片資料夾，也能調整響應式排版。[外掛介紹](https://community.obsidian.md/plugins/gallery-view)

### 8. Supercharged Links

根據筆記的 `status` 或標籤，自動替連結加上顏色、背景或 Emoji。

例如：

- 🔴 緊急
- 🟡 進行中
- 🟢 已完成
- 🔵 等待廠商

很適合跟剛才的 Dataview 工單屬性一起使用，但設定比其他外掛稍微進階。[外掛介紹](https://community.obsidian.md/plugins/supercharged-links-obsidian)

## 我建議你的安裝組合

先安裝這四個就好：

1. **Border Theme**
2. **Style Settings**
3. **Iconic**
4. **Homepage Blocks**
5. **Dataview**

如果有很多設備或施工照片，再加 **Gallery View**；想把客戶和專案顯示成卡片，再加 **Explorer**。

這樣會是乾淨的「FMS 工作台」風格，不需要一次裝十幾個外掛，避免畫面變花、速度也比較穩。

### 10. 還有甚麼推薦的外掛嗎

用途：不必打開「待辦維熹.md」，按一個快捷鍵就能新增待辦。

Tasks 提供視窗選擇日期，不需要自己背 Emoji 語法。[外掛介紹](https://community.obsidian.md/plugins/obsidian-tasks-plugin)

不過，如果你完全不需要日期與循環工作，可以先不裝。

## 3. Commander——做一顆「新增待辦」按鈕

- 左側工具列
- 筆記標題列
- 狀態列
- 右鍵選單

這樣按一下 `＋` 就能輸入新待辦，不必記快捷鍵。

## 4. Buttons——在首頁放漂亮按鈕

可以在首頁製作：

- `＋新增待辦`
- `📋開啟待辦原始檔`
- `✅查看已完成`

並且能配合 Style Settings 調整按鈕外觀。[外掛介紹](https://community.obsidian.md/plugins/buttons)

不過你的 Dashboard 已經有圖形介面，所以 Buttons 屬於選配。

```text
🏠 Dashboard
✅ 待辦維熹
📦 附件
```

也能調整頁籤和側邊工具列圖示顏色。[外掛介紹](https://community.obsidian.md/plugins/iconic)

## 最適合你的精簡組合

建議只使用：

- **Dashboard**：顯示主畫面
- **QuickAdd**：快速新增待辦

Dataview、Cards View、Explorer、Calendar 目前都不是必要的。

### 39. 我要怎麼改

來源：[S115-Q020](<../../原始問答/S115_新增 Obsidian 開機主題圖片.md#q20>)；2026-08-28

**問題**

我要怎麼改

**歷史回答**

最簡單的方法是另外建立一個 CSS 片段，避免改到目前的背景設定。

1. 開啟 Obsidian「設定 → 外觀」
2. 找到「CSS 片段」
3. 點資料夾圖示
4. 建立檔案 `heading-colors.css`
5. 貼上以下內容：

```css
/* H1 大標題 */
.markdown-rendered h1,
.cm-header-1 {
  color: #ff66cc !important;
}

/* H2 標題 */
.markdown-rendered h2,
.cm-header-2 {
  color: #66ccff !important;
}

/* H3 標題 */
.markdown-rendered h3,
.cm-header-3 {
  color: #ffd166 !important;
}
```

儲存後回到 Obsidian，在「CSS 片段」按重新整理，開啟 `heading-colors`。

只想修改大標題 H1，就只保留第一段。`#ff66cc` 是粉紅色，可替換成其他色碼，例如：

- 金色：`#ffd166`
- 淺藍：`#66ccff`
- 紫色：`#c792ea`
- 綠色：`#7bd88f`
- 白色：`#ffffff`

### 43. OBSIDIAN

來源：[S159-Q003](<../../原始問答/S159_確認是否可改為待確認.md#q3>)；2026-09-09

**問題**

OBSIDIAN

**歷史回答**

可以，Obsidian 可以用 **Tasks 外掛**做到「未完成 → 待確認 → 已完成」循環切換。

1. 到 **設定 → 社群外掛**，搜尋 **Tasks**，安裝並啟用。已有安裝就跳過。
2. 到 **設定 → Tasks → Statuses（狀態）**，把狀態設成：

| 狀態名稱 | 符號 | 下一個狀態符號 | 類型 |
|---|---|---|---|
| 未完成 | 空格 | `?` | `TODO` |
| 待確認 | `?` | `x` | `IN_PROGRESS` |
| 已完成 | `x` | 空格 | `DONE` |

其中「待確認」用 **Add New Task Status** 新增，其餘兩個修改原有設定。[官方設定說明](https://publish.obsidian.md/tasks/Getting%20Started/Statuses/Status%20Settings)

設定完成後，使用 Tasks 的 **Toggle task done** 指令，就能依序切換：

```markdown
- [ ] 銷售訂單附件
- [?] 銷售訂單附件
- [x] 銷售訂單附件
```

**問號圖示、顏色，以及待確認是否有刪除線，還需要佈景主題或 CSS 支援**；Tasks 設定負責狀態切換。[外觀說明](https://publish.obsidian.md/tasks/Reference/Status%20Collections/About%20Status%20Collections)
