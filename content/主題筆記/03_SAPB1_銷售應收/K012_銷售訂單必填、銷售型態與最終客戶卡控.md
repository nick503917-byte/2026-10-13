### 2. SQL／程式碼調整與說明

來源：[S107-Q001](<../../原始問答/S107_處理銷售事項.md#q1>)；2026-08-24

**問題**

SELECT T0.[U_SALETYPE], T0.[U_CustOrderNo], T1.[U_FINALPRICETEST] FROM ORDR T0  INNER JOIN RDR1 T1 ON T0.[DocEntry] = T1.[DocEntry]

這幾個欄位 要寫SP卡控必填

**歷史回答**

可放在 SAP Business One 的 `SBO_SP_TransactionNotification` 中，針對銷售訂單新增或更新進行必填卡控：

```sql
/* 銷售訂單必填欄位卡控 */
IF @object_type = '17'
   AND @transaction_type IN ('A', 'U')
BEGIN
    /* 表頭：銷售類型 */
    IF EXISTS (
        SELECT 1
        FROM ORDR T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND ISNULL(LTRIM(RTRIM(T0.U_SALETYPE)), '') = ''
    )
    BEGIN
        SET @error = -1001
        SET @error_message = N'銷售類型為必填欄位，請輸入後再儲存！'
    END

    /* 表頭：客戶訂單號碼 */
    ELSE IF EXISTS (
        SELECT 1
        FROM ORDR T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND ISNULL(LTRIM(RTRIM(T0.U_CustOrderNo)), '') = ''
    )
    BEGIN
        SET @error = -1002
        SET @error_message = N'客戶訂單號碼為必填欄位，請輸入後再儲存！'
    END

    /* 明細：最終價格測試 */
    ELSE IF EXISTS (
        SELECT 1
        FROM RDR1 T1
        WHERE T1.DocEntry = @list_of_cols_val_tab_del
          AND T1.U_FINALPRICETEST IS NULL
    )
    BEGIN
        SET @error = -1003
        SET @error_message = N'銷售訂單明細的最終價格為必填欄位，請確認每一筆明細！'
    END
END
```

如果 `U_FINALPRICETEST` 是數值欄位，而且「0」也要視為未填，條件改成：

```sql
AND ISNULL(T1.U_FINALPRICETEST, 0) = 0
```

若是文字欄位，則改成：

```sql
AND ISNULL(LTRIM(RTRIM(T1.U_FINALPRICETEST)), '') = ''
```

這段應放在 SP 最後輸出 `SELECT @error, @error_message` 之前。

### 3. 草稿也要

來源：[S107-Q002](<../../原始問答/S107_處理銷售事項.md#q2>)；2026-08-24

**問題**

草稿也要

**歷史回答**

草稿物件代碼是 `112`，需再判斷 `ODRF.ObjType = '17'`，確保只卡銷售訂單草稿。

```sql
/* 銷售訂單草稿必填欄位卡控 */
IF @object_type = '112'
   AND @transaction_type IN ('A', 'U')
   AND EXISTS (
       SELECT 1
       FROM ODRF
       WHERE DocEntry = @list_of_cols_val_tab_del
         AND ObjType = '17'
   )
BEGIN
    /* 表頭：銷售類型 */
    IF EXISTS (
        SELECT 1
        FROM ODRF T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND T0.ObjType = '17'
          AND ISNULL(LTRIM(RTRIM(T0.U_SALETYPE)), '') = ''
    )
    BEGIN
        SET @error = -1011
        SET @error_message = N'銷售類型為必填欄位，請輸入後再儲存草稿！'
    END

    /* 表頭：客戶訂單號碼 */
    ELSE IF EXISTS (
        SELECT 1
        FROM ODRF T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND T0.ObjType = '17'
          AND ISNULL(LTRIM(RTRIM(T0.U_CustOrderNo)), '') = ''
    )
    BEGIN
        SET @error = -1012
        SET @error_message = N'客戶訂單號碼為必填欄位，請輸入後再儲存草稿！'
    END

    /* 明細：最終價格 */
    ELSE IF EXISTS (
        SELECT 1
        FROM DRF1 T1
        INNER JOIN ODRF T0
            ON T0.DocEntry = T1.DocEntry
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND T0.ObjType = '17'
          AND T1.U_FINALPRICETEST IS NULL
    )
    BEGIN
        SET @error = -1013
        SET @error_message = N'銷售訂單草稿明細的最終價格為必填欄位，請確認每一筆明細！'
    END
END
```

正式單與草稿都要卡控時，將這段接在前一段正式銷售訂單 `@object_type = '17'` 的程式後面即可。

如果 `U_FINALPRICETEST` 為數值欄位，且 `0` 也視為未填，使用：

```sql
AND ISNULL(T1.U_FINALPRICETEST, 0) = 0
```

### 5. 我要寫 銷售型態的必填 ORDR 的 T0.[U\_SALEPRICE], T0.[U\_SALETYPE], T0.[U\_CUSCODE] RDR1 的 T1.[U\_FINA…

來源：[S142-Q001](<../../原始問答/S142_新增銷售型態必填欄位.md#q1>)；2026-09-08

**問題**

我要寫 銷售型態的必填

ORDR  的 T0.[U\_SALEPRICE], T0.[U\_SALETYPE], T0.[U\_CUSCODE]
RDR1  的  T1.[U\_FINALPRICETEST]

都需要必填

**歷史回答**

可以，在 SAP B1 的 `SBO_SP_TransactionNotification` 加入以下檢核。銷售訂單**新增或更新時**，表頭及每筆明細的指定欄位都必須填寫。

```sql
IF @object_type = '17'
   AND @transaction_type IN ('A', 'U')
BEGIN
    -- 表頭必填
    IF EXISTS (
        SELECT 1
        FROM ORDR T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND (
              NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_SALEPRICE))), '') IS NULL
              OR NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_SALETYPE))), '') IS NULL
              OR NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_CUSCODE))), '') IS NULL
          )
    )
    BEGIN
        SET @error = -1701
        SET @error_message = N'銷售訂單表頭必填：U_SALEPRICE、U_SALETYPE、U_CUSCODE。'
    END
    ELSE IF EXISTS (
        -- 每筆明細必填
        SELECT 1
        FROM RDR1 T1
        WHERE T1.DocEntry = @list_of_cols_val_tab_del
          AND NULLIF(
              LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T1.U_FINALPRICETEST))),
              ''
          ) IS NULL
    )
    BEGIN
        SET @error = -1702
        SET @error_message = N'銷售訂單每筆明細的 U_FINALPRICETEST 必須填寫。'
    END
END
```

放在程序最後的 `SELECT @error, @error_message` **之前**。

此版本適用 **SQL Server**，會擋下 `NULL`、空字串及只有空白的內容；數值 `0` 目前視為已填寫。

### 6. RDR1有個條件 當ORDR DocType= I 則卡控T1.U\_FINALPRICETEST 且不得為0

來源：[S142-Q002](<../../原始問答/S142_新增銷售型態必填欄位.md#q2>)；2026-09-08

**問題**

RDR1有個條件 當ORDR DocType= I 則卡控T1.U\_FINALPRICETEST 且不得為0

**歷史回答**

可以，表頭三個欄位維持必填；明細改為只有 `ORDR.DocType = 'I'` 時，才檢查 `U_FINALPRICETEST` 必填且不得為 `0`。

```sql
IF @object_type = '17'
   AND @transaction_type IN ('A', 'U')
BEGIN
    -- 表頭必填
    IF EXISTS (
        SELECT 1
        FROM ORDR T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND (
              NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_SALEPRICE))), '') IS NULL
              OR NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_SALETYPE))), '') IS NULL
              OR NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_CUSCODE))), '') IS NULL
          )
    )
    BEGIN
        SET @error = -1701
        SET @error_message = N'銷售訂單表頭必填：U_SALEPRICE、U_SALETYPE、U_CUSCODE。'
    END
    ELSE IF EXISTS (
        -- 物料類型訂單：每筆明細必填且不得為 0
        SELECT 1
        FROM ORDR T0
        INNER JOIN RDR1 T1 ON T0.DocEntry = T1.DocEntry
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND T0.DocType = 'I'
          AND (
              NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T1.U_FINALPRICETEST))), '') IS NULL
              OR T1.U_FINALPRICETEST = 0
          )
    )
    BEGIN
        SET @error = -1702
        SET @error_message = N'物料類型銷售訂單，每筆明細的 U_FINALPRICETEST 必填且不得為 0。'
    END
END
```

此版本假設 `U_FINALPRICETEST` 為數值欄位，放在 `SBO_SP_TransactionNotification` 最後的 `SELECT @error, @error_message` 之前。
