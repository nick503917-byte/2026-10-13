## S067-Q001｜SAPB1 存貨稽核報表 功能

日期：2026-08-11

**你的提問**

SAPB1 存貨稽核報表 功能

**當時回答**

SAP Business One 的「存貨稽核報表（Inventory Audit Report）」主要用來追蹤存貨數量與價值的異動，並核對「存貨模組」和「總帳存貨科目」是否一致。

功能重點：

- 顯示每筆存貨交易造成的數量與金額變化。
- 查看期初數量／金額、交易異動及期末累計數量／價值。
- 依品項、倉庫、品項群組、存貨科目與日期範圍篩選。
- 可按「品項」檢視，或按「會計科目」彙總。
- 可追查來源單據，例如收貨採購單、交貨、庫存收發、盤點過帳、生產及存貨重估。
- 可比較報表中的存貨價值與總帳存貨科目餘額。
- 累計數量或價值為負數時，展開明細會以紅色標示。
- 報表可以列印，並可使用 PLD 調整版面。

操作路徑：

`存貨 → 存貨報表 → 存貨稽核報表`

常見查詢條件：

- 過帳日期或系統日期
- 起訖日期
- 品項編號、品項群組或屬性
- 倉庫
- 存貨科目
- 依品項／依科目彙總
- 顯示期間內無交易但有期初餘額的品項

主要欄位：

| 欄位 | 意義 |
|---|---|
| Quantity | 該筆交易造成的數量增減 |
| Cost | 該筆交易的單位成本 |
| Trans. Value | 過帳至存貨科目的交易價值 |
| Cumulative Qty | 交易後的累計庫存量 |
| Cumulative Value | 交易後的累計存貨價值 |
| Balance from G/L | 總帳存貨科目餘額 |

需要特別注意：

1. 此報表適用於採用「永續盤存制」的公司。
2. 它不會重新計算成本，而是呈現資料庫中已過帳的成本與存貨交易。
3. 如果有人直接對存貨科目做手動分錄，總帳餘額可能與存貨稽核報表不同；應先排除非存貨交易再比較。
4. 過帳日期與系統日期不同的交易可能以藍色顯示，核對歷史期間時尤其要注意。
5. 它不是「實體盤點差異表」；實際庫存盤點與調整應使用「存貨盤點／存貨過帳」功能。
6. 若採序號／批次評價法，應使用「批次及序號存貨稽核報表」，才能追到個別批號或序號。

官方說明：[Inventory Audit Report](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/4522e91373c80108e10000000a114a6b.html)、[Selection Criteria](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/4522e90a73c80108e10000000a114a6b.html)、[與總帳餘額差異原因](https://help.sap.com/docs/SAP_BUSINESS_ONE/87e1767ca7584b8f8d60775347637b07/84adeac14a494349a153dd2fed7d60be.html)。

## S067-Q002｜稽核報表的項目成本 跟我 項目主檔看到的成本 有一點不同是正常的嗎

日期：2026-08-11

**你的提問**

## My request:
稽核報表的項目成本 跟我 項目主檔看到的成本 有一點不同是正常的嗎

**當時回答**

是的，差一點通常是正常的，因為兩邊顯示的成本不一定是同一個時間點與計算口徑。

- 「項目主檔 → 存貨資料」的項目成本，通常是目前最新成本。
- 稽核報表明細的 `Cost`，是該筆存貨交易發生當時使用的成本。
- 稽核報表彙總列的成本，則依累計存貨價值與累計數量計算；不是直接讀取項目主檔的目前成本。SAP 官方也明確說明，報表不能直接使用目前的項目成本回推歷史交易。[SAP 官方說明](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/4522e91373c80108e10000000a114a6b.html)

常見的正常差異原因包括：

1. 查詢截止日不同  
   例如稽核報表做到 7 月 31 日，但項目主檔顯示的是今天的成本；8 月發生過進貨、附加費用或存貨重估，兩者自然不同。

2. 四捨五入  
   畫面可能只顯示 2～6 位小數，但 SAP 內部以更高精度保存。單價看似不同一點，乘上數量後通常仍能對上存貨價值。

3. 依倉庫管理成本  
   若公司勾選「依倉庫管理項目成本」，每個倉庫可能有不同成本。報表若合併多個倉庫，而主檔查看的是某一倉庫，兩者便不能直接比較。[SAP 官方說明](https://help.sap.com/docs/SAP_BUSINESS_ONE/87e1767ca7584b8f8d60775347637b07/58cb74ac9f654cc582dfa80b48fdfe04.html)

4. 評價方法不同  
   移動平均法、標準成本法、FIFO，以及序號／批次評價法的成本意義不同。FIFO 的主檔成本尤其不一定等於某一筆歷史出庫的層別成本。

5. 後續成本調整  
   到岸成本、存貨重估、以收貨採購單為基礎的應付發票價差等，可能只改變存貨價值而沒有數量異動。

建議用這個方式核對：

- 稽核報表截止日設為今天。
- 選擇同一個品項及相同倉庫範圍。
- 若為依倉庫管理成本，勾選「按倉庫分組」。
- 查看最後一列：
  `累計價值 ÷ 累計數量`
- 將結果與項目主檔相同倉庫的成本比較。

若只是小數末位不同，多半是顯示精度／四捨五入；但若差異明顯，或「累計價值 ÷ 累計數量」也對不上，便要檢查負庫存、存貨重估、到岸成本、日期條件及倉庫成本設定。
