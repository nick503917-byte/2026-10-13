## S186-Q001｜IF(S80=0,IF(R80<0,R80,0),0) EXCEL攻勢

日期：2026-09-17

**你的提問**

IF(S80=0,IF(R80<0,R80,0),0) EXCEL攻勢

**當時回答**

這個 Excel 公式：

```excel
=IF(S80=0,IF(R80<0,R80,0),0)
```

意思是：**當 S80 等於 0，而且 R80 小於 0 時，顯示 R80；其餘情況都顯示 0。**

| S80 | R80 | 結果 |
|---:|---:|---:|
| 0 | -100 | -100 |
| 0 | 100 | 0 |
| 5 | -100 | 0 |

也可以改寫成：

```excel
=IF(AND(S80=0,R80<0),R80,0)
```
