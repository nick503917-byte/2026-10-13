## S054-Q003｜重新給我一份

日期：2026-08-06

**你的提問**

重新給我一份

**當時回答**

```sql
/* 銷售退貨請求、銷售退貨：限制表身退貨原因 */
IF @object_type IN ('234000031', '16')
   AND @transaction_type IN ('A', 'U')
BEGIN
    IF
    (
        (
            @object_type = '234000031'
            AND EXISTS
            (
                SELECT 1
                FROM RRR1 T0
                WHERE T0.DocEntry = @list_of_cols_val_tab_del
                  AND T0.U_ReturnReason IN
                      ('RR11', 'RR12', 'RR13', 'RR14', 'RR15', 'RR16')
            )
        )
        OR
        (
            @object_type = '16'
            AND EXISTS
            (
                SELECT 1
                FROM RDN1 T0
                WHERE T0.DocEntry = @list_of_cols_val_tab_del
                  AND T0.U_ReturnReason IN
                      ('RR11', 'RR12', 'RR13', 'RR14', 'RR15', 'RR16')
            )
        )
    )
    BEGIN
        SET @error = 1601
        SET @error_message = N'退貨原因不可選擇 RR11、RR12、RR13、RR14、RR15、RR16。'
    END
END
```

- `234000031`：銷售退貨請求 `RRR1`
- `16`：銷售退貨 `RDN1`
- 適用新增 `A` 與更新 `U`。
