## S188-Q004｜有資源

日期：2026-09-18

**你的提問**

有資源

**當時回答**

有資源的話，**必須把「實際資源元件成本」一起計入**，不能只比較材料成本與產品成本。

如果沒有額外成本及副產品，卡控條件就是：

```text
差異＝實際產品成本
    －（實際項目元件成本＋實際資源元件成本）

差異絕對值 > 允許誤差 → 禁止轉為「已結」
```

例如：

| 項目 | 金額（VND） |
|---|---:|
| 實際項目元件成本 | 100,000 |
| 實際資源元件成本 | 20,000 |
| 實際產品成本 | 120,000 |
| 差異 | 0 → 允許結單 |

若產品成本只有 **100,000**，差異就是 **−20,000**，應阻擋結單。

**建議程式直接採完整公式**，之後出現額外成本或副產品也能正確判斷：

```text
差異＝（實際產品成本＋副產品實際成本）
    －（實際項目元件成本＋實際資源元件成本＋實際額外成本）
```

這符合 [SAP 的總計差異定義](https://help.sap.com/doc/10311afc90c643b3aaceeaa87a52bf5f/10.0/en-US/How_to_Work_with_Resources_and_Production_in_SAP_Business_One.pdf)。SQL Server 的卡控仍要檢核**結單調整前的差異**，並以實際已發出的資源成本計算，不能拿 BOM 預計資源成本代替。

```sql
ELSE IF ABS(@WS_PC_Diff) > @WS_PC_Tolerance
    AND NOT EXISTS (
        SELECT 1
        FROM dbo.OWOR W
        INNER JOIN dbo.OUSR U
            ON U.USERID = W.UserSign2
        WHERE W.DocEntry = @WS_PC_Entry
          AND U.USER_CODE IN (
              N'USER_A',   -- 換成允許放行的 SAP 登入帳號
```

```sql
AND U.USER_CODE IN (

    N'USER_B',
```

```sql
SELECT USERID, USER_CODE AS [登入帳號], U_NAME AS [使用者名稱]
```

之後成本規則、允許誤差及放行帳號，都集中修改獨立程序：

```sql
dbo.WS_SP_CheckProductionCloseCost
```

**放行名單預設為空**，裡面已附新增帳號範例；其他既有卡控仍保留。
