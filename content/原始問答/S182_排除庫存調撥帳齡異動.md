**當時回答**

了解，你要顯示的是 **「提列減損金額＝平均成本 × 該區間數量 × 減損比率」**。

依圖片提供的比率，1–30 天為 **1%**、31–90 天為 **5%**、91 天以上為 **100%**。把原 SQL 最後的 `SELECT` 到結尾換成以下內容，前面的 CTE 保留：

```sql
SELECT
    P.AsOfDate AS [帳齡基準日],
    I.ItemCode AS [料號],
    I.ItemName AS [品名],
    I.InvntryUom AS [庫存單位],
    ISNULL(I.AvgPrice, 0) AS [平均成本],

    ISNULL(T.TotalIn, 0)
        - ISNULL(T.TotalOut, 0) AS [庫存結存量],

    ISNULL(I.AvgPrice, 0)
        * (
            ISNULL(T.TotalIn, 0)
            - ISNULL(T.TotalOut, 0)
          ) AS [庫存結存值],

    ISNULL(A.Age0130, 0) AS [1-30天],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age0130, 0)
        * 0.01 AS [1-30天提列減損金額(1%)],

    ISNULL(A.Age3190, 0) AS [31-90天],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age3190, 0)
        * 0.05 AS [31-90天提列減損金額(5%)],

    ISNULL(I.AvgPrice, 0)

        * 1.00 AS [91-180天提列減損金額(100%)],

    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age181365, 0)
        * 1.00 AS [181-365天提列減損金額(100%)],

    ISNULL(I.AvgPrice, 0)

    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age2To3Years, 0)

            CASE WHEN AgeDays > 1095
                 THEN RemainingQty ELSE 0 END
        ) AS AgeOver3Years

    FROM Remaining
    GROUP BY ItemCode
)
SELECT
    P.AsOfDate AS [帳齡基準日],
    I.ItemCode AS [料號],
    I.ItemName AS [品名],
    I.InvntryUom AS [庫存單位],
    ISNULL(I.AvgPrice, 0) AS [平均成本],

    ISNULL(T.TotalIn, 0)
        - ISNULL(T.TotalOut, 0) AS [庫存結存量],

    ISNULL(I.AvgPrice, 0)
        * (
            ISNULL(T.TotalIn, 0)
            - ISNULL(T.TotalOut, 0)
          ) AS [庫存結存值],

    ISNULL(A.Age0130, 0) AS [1-30天],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age0130, 0)
        * 0.01 AS [1-30天提列減損金額(1%)],

    ISNULL(A.Age3190, 0) AS [31-90天],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age3190, 0)
        * 0.05 AS [31-90天提列減損金額(5%)],

    ISNULL(A.Age91180, 0) AS [91-180天],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age91180, 0)
        * 1.00 AS [91-180天提列減損金額(100%)],

    ISNULL(A.Age181365, 0) AS [181-365天],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age181365, 0)
        * 1.00 AS [181-365天提列減損金額(100%)],

    ISNULL(A.Age1To2Years, 0) AS [1-2年],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age1To2Years, 0)
        * 1.00 AS [1-2年提列減損金額(100%)],

    ISNULL(A.Age2To3Years, 0) AS [2-3年],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.Age2To3Years, 0)
        * 1.00 AS [2-3年提列減損金額(100%)],

    ISNULL(A.AgeOver3Years, 0) AS [3年以上],
    ISNULL(I.AvgPrice, 0)
        * ISNULL(A.AgeOver3Years, 0)
        * 1.00 AS [3年以上提列減損金額(100%)]

FROM OITM I
LEFT JOIN Totals T
    ON T.ItemCode = I.ItemCode
LEFT JOIN Aging A
    ON A.ItemCode = I.ItemCode
CROSS JOIN Params P

WHERE I.InvntItem = 'Y'
  AND
  (
      ISNULL(T.TotalIn, 0) - ISNULL(T.TotalOut, 0) <> 0
      OR ISNULL(A.AgedQty, 0) <> 0
  )

ORDER BY I.ItemCode;
```

沿用目前設定：**0 天併入 1–30 天、提列 1%**，未套用圖片的「未逾期 0.03%」。金額使用目前 `I.AvgPrice`，不是歷史基準日成本；取消單據仍按目前取消狀態排除。
