## S142-Q001｜我要寫 銷售型態的必填 ORDR 的 T0.[U\_SALEPRICE], T0.[U\_SALETYPE], T0.[U\_CUSCODE] RDR1 的 T1.[U\_FINA…

日期：2026-09-08

**你的提問**

我要寫 銷售型態的必填

ORDR  的 T0.[U\_SALEPRICE], T0.[U\_SALETYPE], T0.[U\_CUSCODE]
RDR1  的  T1.[U\_FINALPRICETEST]

都需要必填

**當時回答**

可以，在 SAP B1 的 `SBO_SP_TransactionNotification` 加入以下檢核。銷售訂單**新增或更新時**，表頭及每筆明細的指定欄位都必須填寫。

```sql
IF @object_type = '17'
   AND @transaction_type IN ('A', 'U')
BEGIN
    -- 表頭必填
    IF EXISTS (
        SELECT 1
        FROM ORDR T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND (
              NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_SALEPRICE))), '') IS NULL
              OR NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_SALETYPE))), '') IS NULL
              OR NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_CUSCODE))), '') IS NULL
          )
    )
    BEGIN
        SET @error = -1701
        SET @error_message = N'銷售訂單表頭必填：U_SALEPRICE、U_SALETYPE、U_CUSCODE。'
    END
    ELSE IF EXISTS (
        -- 每筆明細必填
        SELECT 1
        FROM RDR1 T1
        WHERE T1.DocEntry = @list_of_cols_val_tab_del
          AND NULLIF(
              LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T1.U_FINALPRICETEST))),
              ''
          ) IS NULL
    )
    BEGIN
        SET @error = -1702
        SET @error_message = N'銷售訂單每筆明細的 U_FINALPRICETEST 必須填寫。'
    END
END
```

放在程序最後的 `SELECT @error, @error_message` **之前**。

此版本適用 **SQL Server**，會擋下 `NULL`、空字串及只有空白的內容；數值 `0` 目前視為已填寫。

## S142-Q002｜RDR1有個條件 當ORDR DocType= I 則卡控T1.U\_FINALPRICETEST 且不得為0

日期：2026-09-08

**你的提問**

RDR1有個條件 當ORDR DocType= I 則卡控T1.U\_FINALPRICETEST 且不得為0

**當時回答**

可以，表頭三個欄位維持必填；明細改為只有 `ORDR.DocType = 'I'` 時，才檢查 `U_FINALPRICETEST` 必填且不得為 `0`。

```sql
IF @object_type = '17'
   AND @transaction_type IN ('A', 'U')
BEGIN
    -- 表頭必填
    IF EXISTS (
        SELECT 1
        FROM ORDR T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND (
              NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_SALEPRICE))), '') IS NULL
              OR NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_SALETYPE))), '') IS NULL
              OR NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T0.U_CUSCODE))), '') IS NULL
          )
    )
    BEGIN
        SET @error = -1701
        SET @error_message = N'銷售訂單表頭必填：U_SALEPRICE、U_SALETYPE、U_CUSCODE。'
    END
    ELSE IF EXISTS (
        -- 物料類型訂單：每筆明細必填且不得為 0
        SELECT 1
        FROM ORDR T0
        INNER JOIN RDR1 T1 ON T0.DocEntry = T1.DocEntry
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND T0.DocType = 'I'
          AND (
              NULLIF(LTRIM(RTRIM(CONVERT(NVARCHAR(MAX), T1.U_FINALPRICETEST))), '') IS NULL
              OR T1.U_FINALPRICETEST = 0
          )
    )
    BEGIN
        SET @error = -1702
        SET @error_message = N'物料類型銷售訂單，每筆明細的 U_FINALPRICETEST 必填且不得為 0。'
    END
END
```

此版本假設 `U_FINALPRICETEST` 為數值欄位，放在 `SBO_SP_TransactionNotification` 最後的 `SELECT @error, @error_message` 之前。
