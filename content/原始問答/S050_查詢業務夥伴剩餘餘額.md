**你的提問**

如果我要寫一隻 查詢報表

跟 OCRD的 BALANCE的這個欄位很像。

我想知道這個業務夥伴的剩下餘額 以及明細

**當時回答**

在 SAP Business One 裡，`OCRD.Balance` 是業務夥伴「目前的總帳餘額」。如果要查看這個餘額由哪些未結清交易組成，建議從 `JDT1` 的未清餘額欄位查詢，而不是直接加總發票金額。

以下是 SQL Server 版，可直接放進 SAP B1 Query Manager。

### 業務夥伴餘額與未清明細

```sql
/* [%0] = 業務夥伴代碼 */

SELECT
    BP.CardCode                         AS N'業務夥伴代碼',
    BP.CardName                         AS N'業務夥伴名稱',
    BP.Balance                          AS N'OCRD目前餘額',

    T.TransId                           AS N'分錄號碼',
    T.Line_ID                           AS N'分錄列號',
    H.RefDate                           AS N'過帳日期',
    H.DueDate                           AS N'到期日',
    H.TaxDate                           AS N'文件日期',

    CASE H.TransType
        WHEN 13  THEN N'應收發票'
        WHEN 14  THEN N'應收貸項'
        WHEN 18  THEN N'應付發票'
        WHEN 19  THEN N'應付貸項'
        WHEN 24  THEN N'收款'
        WHEN 46  THEN N'付款'
        WHEN 30  THEN N'手動分錄'
        WHEN 203 THEN N'應收預付款'
        WHEN 204 THEN N'應付預付款'
        ELSE N'其他交易'
    END                                 AS N'交易類型',

    H.BaseRef                           AS N'來源文件號',
    H.Memo                              AS N'摘要',
    T.Ref1                              AS N'參考一',
    T.Ref2                              AS N'參考二',

    T.Debit                             AS N'借方金額',
    T.Credit                            AS N'貸方金額',
    T.BalDueDeb                         AS N'未清借方',
    T.BalDueCred                        AS N'未清貸方',

    T.BalDueDeb - T.BalDueCred          AS N'剩餘餘額',

    CASE
        WHEN H.DueDate < CAST(GETDATE() AS DATE)
        THEN DATEDIFF(DAY, H.DueDate, CAST(GETDATE() AS DATE))
        ELSE 0
    END                                 AS N'逾期天數'

FROM OCRD BP
INNER JOIN JDT1 T
    ON T.ShortName = BP.CardCode
INNER JOIN OJDT H
    ON H.TransId = T.TransId

WHERE BP.CardCode = '[%0]'
  AND ABS(T.BalDueDeb - T.BalDueCred) > 0.001

ORDER BY
    H.DueDate,
    H.RefDate,
    T.TransId;
```

### 查詢全部業務夥伴的餘額摘要

```sql
SELECT
    BP.CardCode                             AS N'業務夥伴代碼',
    BP.CardName                             AS N'業務夥伴名稱',
    CASE BP.CardType
        WHEN 'C' THEN N'客戶'
        WHEN 'S' THEN N'供應商'
        WHEN 'L' THEN N'潛在客戶'
    END                                     AS N'類型',
    BP.Currency                             AS N'幣別',
    BP.Balance                              AS N'OCRD餘額',
    SUM(
        ISNULL(T.BalDueDeb, 0)
        - ISNULL(T.BalDueCred, 0)
    )                                       AS N'未清明細合計'

FROM OCRD BP
LEFT JOIN JDT1 T
    ON T.ShortName = BP.CardCode
   AND ABS(T.BalDueDeb - T.BalDueCred) > 0.001

WHERE BP.CardType IN ('C', 'S')

GROUP BY
    BP.CardCode,
    BP.CardName,
    BP.CardType,
    BP.Currency,
    BP.Balance

HAVING
       ABS(BP.Balance) > 0.001
    OR ABS(SUM(
        ISNULL(T.BalDueDeb, 0)
        - ISNULL(T.BalDueCred, 0)
    )) > 0.001

ORDER BY BP.CardCode;
```

重要觀念：

- `OCRD.Balance`：業務夥伴目前的本幣總帳餘額。
- `JDT1.BalDueDeb - JDT1.BalDueCred`：每一筆分錄目前尚未沖銷的餘額。
- 正數通常代表應收／借方餘額；負數通常代表預收、貸項或應付／貸方餘額。
- 明細應包含發票、貸項、收付款及手動分錄，才有機會與 `OCRD.Balance` 對上。
- 如果業務夥伴使用外幣，需改用 `BalFcDeb`、`BalFcCred`，並依 `FCCurrency` 分組；系統幣則使用 `BalScDeb`、`BalScCred`。
- 若報表要查「歷史某一天的餘額」，不能直接使用現在的 `BalDueDeb/BalDueCred`，因為這些欄位反映目前沖銷狀態，需要另外依內部沖銷日期回推。

**當時回答**

你目前的條件：

```sql
AND ISNULL(L.ItemCode,'') <> ''
```

實際上只會卡到 `DocType = 'I'` 的項目文件；服務型文件 `DocType = 'S'` 通常沒有 `ItemCode`，因此會被排除。

請把一般退貨文件的條件改成：

```sql
AND H.DocType IN ('I', 'S')
AND (
       H.DocType = 'S'
    OR ISNULL(L.ItemCode, '') <> ''
)
```

Credit Memo 還要把 `NoInvtryMv` 限制只套用到項目型文件：

```sql
AND H.DocType IN ('I', 'S')
AND
(
    H.DocType = 'S'
    OR
    (
        H.DocType = 'I'
        AND ISNULL(L.ItemCode, '') <> ''
        AND ISNULL(L.NoInvtryMv, 'N') = 'N'
    )
)
```

這次不是日期內容錯誤，而是你在 SQL Server Management Studio（SSMS）執行了 SAP B1 Query Manager 專用語法。

`[%0]`、`[%1]`、`[%2]` 只有 SAP B1 查詢管理員會自動替換。在 SSMS 裡，它們仍然是原始文字：

```sql
'[%1]'
```

所以無法轉換成日期。

如果在 SSMS 測試，請將參數區改成固定值：

```sql
DECLARE @CardCode NVARCHAR(50)
DECLARE @DateFrom DATE
DECLARE @DateTo DATE

SET @CardCode = N'SS0021'
SET @DateFrom = DATEFROMPARTS(2026, 1, 1)
SET @DateTo   = DATEFROMPARTS(2026, 12, 31)
```

並刪除原本這整段參數設定：

```sql
/* SELECT FROM [dbo].[OCRD] P0 */
...

IF @DateFrom IS NULL OR @DateTo IS NULL
BEGIN
    ...
END
```

如果是在 SAP B1 的「查詢管理員」執行，則繼續使用目前下載檔案，不要直接在 SSMS 執行。SAP B1 執行時會依序跳出三個參數輸入框：

1. 業務夥伴代碼
2. 開始日期
3. 結束日期

簡單來說：

- SAP B1 查詢管理員：使用 `[%0]` 版本。
- SSMS 測試：使用上面的固定值版本。

## S050-Q013｜可以用了 但我想要優化 關於 如果我想要知道單據號碼可以嗎

日期：2026-08-05

**你的提問**

可以用了 但我想要優化 關於 如果我想要知道單據號碼可以嗎

**當時回答**

可以，已加入单据号码相关栏位：

- `单据类型`：例如 A/R 发票、收款、手动日记账分录。
- `ObjType`：SAP B1 对象类型。
- `单据号码`：一般来源于 `OJDT.BaseRef`，对应画面上的 `DocNum`。
- `DocEntry`：来源单据内部键值，取自 `OJDT.CreatedBy`。
- `分录号码`：保留 `TransId`，方便追查会计分录。

[下载优化后的查询](C:\Users\nick_yeh\Documents\Codex\2026-08-05\new-chat-3\outputs\bp-open-balance-sapb1-simple.sql)

主要逻辑：

```sql
CASE
    WHEN H.TransType = 30
        THEN CONVERT(NVARCHAR(100), H.TransId)
    ELSE ISNULL(
        NULLIF(H.BaseRef, ''),
        CONVERT(NVARCHAR(100), H.TransId)
    )
END AS N'單據號碼'
```

手动日记账分录没有营销单据 `DocNum`，所以会显示分录号码；发票、贷项、收付款等则显示来源单据号码。

需要注意：`DocEntry` 是系统内部键值，不等于用户在 SAP B1 画面看到的单据号码。后续如果要做黄色箭头钻取原始单据，会同时需要 `ObjType` 和 `DocEntry`。
