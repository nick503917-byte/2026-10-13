## S066-Q001｜CR報表可以做出條碼嗎

日期：2026-08-11

**你的提問**

CR報表可以做出條碼嗎

**當時回答**

可以。若你指的是 **Crystal Reports（CR 報表）**，常見做法有：

- **條碼字型**：安裝 Code 39、Code 128 等字型，再用公式欄位產生符合規格的字串。Code 39 最簡單，例如在資料前後加 `*`。
- **條碼元件／UFL**：適合 Code 128、EAN-13、GS1 等需要校驗碼或編碼轉換的格式。
- **條碼圖片**：由程式或條碼服務產生 PNG，再放進報表；QR Code 通常也可採用這種方式。

要注意：執行報表的電腦與報表伺服器都必須安裝相同字型或元件，否則匯出 PDF、列印時可能只顯示一般文字。

告訴我你的 **CR 版本、條碼種類（Code 128／Code 39／QR Code）以及資料範例**，我可以直接給你公式與設定方式。

## S066-Q002｜不太懂 可以有示範或是說明嗎

日期：2026-08-11

**你的提問**

不太懂 可以有示範或是說明嗎

**當時回答**

可以，先用最簡單的 **Code 39 一維條碼**示範。假設要把訂單編號 `A12345` 顯示成條碼。

### 原理

CR 報表不是直接把文字變成條碼，而是：

`訂單編號 A12345` → 公式加上起訖符號 → `*A12345*` → 套用條碼字型 → 顯示成條碼

### 操作步驟

1. 在製作報表的電腦安裝 **Code 39 條碼字型**。
2. 開啟 Crystal Reports 報表。
3. 在「欄位總管」中找到「公式欄位」。
4. 按右鍵選擇「新增」，名稱可輸入 `訂單條碼`。
5. 輸入以下公式：

```crystal
"*" + UpperCase({訂單.訂單編號}) + "*"
```

如果只是先測試，可以直接輸入：

```crystal
"*A12345*"
```

6. 將 `訂單條碼` 公式欄位拖到報表。
7. 選取該欄位，把字型改成安裝好的 **Code 39 條碼字型**。
8. 將字體大小調成約 `28～36 pt`，並預留左右空白。
9. 預覽或列印後，用條碼掃描器或手機條碼 App 測試。

正常情況下，畫面會顯示條碼，掃描結果則是：

```text
A12345
```

前後的 `*` 是 Code 39 的開始與結束符號，掃描結果通常不會包含它們。

### 常見問題

- 顯示成 `*A12345*` 普通文字：代表尚未安裝或尚未選擇條碼字型。
- 匯出 PDF 後不是條碼：產生 PDF 的電腦或報表伺服器也要安裝該字型。
- 掃描不到：把條碼放大，左右保留空白，避免欄位被截斷。
- 內容有中文：Code 39 不能直接編碼中文，通常改用 QR Code。
- 要使用 Code 128：不能只更換字型，通常還需要編碼公式或條碼元件。
