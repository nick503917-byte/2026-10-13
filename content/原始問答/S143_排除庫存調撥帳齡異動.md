## S143-Q001｜sapb1 有關於庫存帳齡的報表 但因為她只要有異動 就會有 但我想排除 庫存調撥的部分 可以嗎

**當時回答**

可以，**但要看你現在用的是 SAP B1 標準報表，還是客製查詢報表。**

你描述的需求，我理解是：**庫存調撥仍要計入各倉庫數量，但不要因為調撥，就把庫存帳齡重新起算。**

例如：

- 1/1 進貨，放在 A 倉。
- 6/1 從 A 倉調撥到 B 倉。
- 6/30 看帳齡時，希望從 **1/1** 起算，而不是 6/1。

這種需求可以透過報表邏輯處理，但有兩種情況：

| 目前報表算法 | 調整方式 |
|---|---|
| 依「最後異動日」計算未動天數 | 取最後異動日時，排除庫存調撥 |
| 依「原始入庫日」計算現存庫存帳齡 | 調撥後要保留或追溯原始入庫日期 |

**不要直接把所有調撥資料刪掉或過濾掉**，否則按倉庫看的庫存數量可能不正確。SAP 官方也說明，調撥通常不影響整體庫存總量，但會涉及各倉庫的移轉。[SAP 官方說明](https://help.sap.com/docs/SAP_BUSINESS_ONE/6b5ba20510a244d0a005150566f01415/f91c6351c8434b69aa733a8d228a4f18.html)

## S143-Q010｜不會

日期：2026-09-09

**你的提問**

## My request:
不會

**當時回答**

那可以先用下面這份查詢：**各倉庫數量取目前批號結存，帳齡統一取批號的入庫日期，因此不會使用調撥日期重新計算。**

但有一個前提：**批號主檔的 `InDate` 必須與你要的原始入庫日一致**。它是可設定的批號日期，不能直接保證等於第一張進貨單的過帳日。SAP 官方欄位說明可參考 [批號日期](https://help.sap.com/doc/089315d8d0f8475a9fc84fb919b501a3/10.0/en-US/SDKHelp/SAPbobsCOM~BatchNumbers~AddmisionDate.html)及[各倉庫批號數量](https://help.sap.com/doc/089315d8d0f8475a9fc84fb919b501a3/10.0/en-US/SDKHelp/OBTQ.html)。

可在 SQL Server 版 SAP B1 的查詢管理員新增以下查詢：

```sql
SELECT
    T.ItemCode                     AS [料號],
    T.ItemName                     AS [品名],
    T.DistNumber                   AS [批號],
    T.WhsCode                      AS [倉庫代碼],
    T.WhsName                      AS [倉庫名稱],
    T.Quantity                     AS [目前庫存數量],
    T.InDate                       AS [批號入庫日期],
    T.AgeDays                      AS [帳齡天數],

    CASE WHEN T.AgeDays BETWEEN 0 AND 30
         THEN T.Quantity ELSE 0 END AS [0至30天],

    CASE WHEN T.AgeDays BETWEEN 31 AND 60
         THEN T.Quantity ELSE 0 END AS [31至60天],

    CASE WHEN T.AgeDays BETWEEN 61 AND 90
         THEN T.Quantity ELSE 0 END AS [61至90天],

    CASE WHEN T.AgeDays BETWEEN 91 AND 180
         THEN T.Quantity ELSE 0 END AS [91至180天],

    CASE WHEN T.AgeDays BETWEEN 181 AND 365
         THEN T.Quantity ELSE 0 END AS [181至365天],

    CASE WHEN T.AgeDays > 365
         THEN T.Quantity ELSE 0 END AS [超過365天],

    CASE WHEN T.AgeDays IS NULL OR T.AgeDays < 0
         THEN T.Quantity ELSE 0 END AS [日期異常數量]

FROM
(
    SELECT
        Q.ItemCode,
        I.ItemName,
        B.DistNumber,
        Q.WhsCode,
        W.WhsName,
        Q.Quantity,
        B.InDate,
        DATEDIFF(
            DAY,
            B.InDate,
            CONVERT(date, GETDATE())
        ) AS AgeDays
    FROM OBTQ Q
    INNER JOIN OBTN B
        ON B.ItemCode  = Q.ItemCode
       AND B.SysNumber = Q.SysNumber
    INNER JOIN OITM I
        ON I.ItemCode = Q.ItemCode
    INNER JOIN OWHS W
        ON W.WhsCode = Q.WhsCode
    WHERE Q.Quantity <> 0
) T
ORDER BY
    T.ItemCode,
    T.DistNumber,
    T.WhsCode
```

**這版是「截至今天的庫存數量帳齡」，沒有金額，也不能直接用來查歷史月底結存。** 我尚未連到你的資料庫實測。

先挑一個曾經調撥的批號核對：各倉數量是否正確，以及「批號入庫日期」是否等於原始進貨日期。如果日期不一致，就需要改成追溯原始入庫單據，不能直接用這個欄位。

## S143-Q015｜剩餘庫存帳齡

日期：2026-09-16

**你的提問**

## My request:
剩餘庫存帳齡

**當時回答**

好，那就做 **「剩餘庫存帳齡，按 FIFO 先進先出計算」**，不再用最後異動日。

以下 SQL 依你指定的範圍：

| 方向 | 納入條件 |
|---|---|
| 入庫 | 收貨採購單 |
| 入庫 | 生產收貨，或 `OIGN.Series = 19` |
| 出庫 | 生產發貨，或 `OIGE.Series = 20` |
| 出庫 | 交貨單 |

**同時符合生產單據及 Series 的明細只計一次；調撥不計入。**

這版先算**截至今天、全公司按料號彙總**的數量帳齡，不分倉、不依批號分配。若之後要分倉，仍須加入調撥的數量流向，才能將原始庫齡帶到調入倉。

```sql
;WITH Movements AS
(
    -- 入庫：收貨採購單
    SELECT
        L.ItemCode,
        H.DocDate,
        20 AS DocType,
        H.DocEntry,
        L.LineNum,
        L.InvQty AS InQty,
        CAST(0 AS decimal(19, 6)) AS OutQty
    FROM OPDN H
    INNER JOIN PDN1 L ON L.DocEntry = H.DocEntry
    WHERE H.CANCELED = 'N'
      AND H.DocDate < DATEADD(DAY, 1, CONVERT(date, GETDATE()))

    UNION ALL

    -- 入庫：生產收貨，或指定 Series 的收貨單
    SELECT
        L.ItemCode,
        H.DocDate,
        59,
        H.DocEntry,
        L.LineNum,
        L.InvQty,
        CAST(0 AS decimal(19, 6))
    FROM OIGN H
    INNER JOIN IGN1 L ON L.DocEntry = H.DocEntry
    WHERE H.CANCELED = 'N'
      AND H.DocDate < DATEADD(DAY, 1, CONVERT(date, GETDATE()))
      AND (L.BaseType = 202 OR H.Series = 19)

    UNION ALL

    -- 出庫：生產發貨，或指定 Series 的發貨單
    SELECT
        L.ItemCode,
        H.DocDate,
        60,
        H.DocEntry,
        L.LineNum,
        CAST(0 AS decimal(19, 6)),
        L.InvQty
    FROM OIGE H
    INNER JOIN IGE1 L ON L.DocEntry = H.DocEntry
    WHERE H.CANCELED = 'N'
      AND H.DocDate < DATEADD(DAY, 1, CONVERT(date, GETDATE()))
      AND (L.BaseType = 202 OR H.Series = 20)

    UNION ALL

    -- 出庫：交貨單
    SELECT
        L.ItemCode,
        H.DocDate,
        15,
        H.DocEntry,
        L.LineNum,
        CAST(0 AS decimal(19, 6)),
        L.InvQty
    FROM ODLN H
    INNER JOIN DLN1 L ON L.DocEntry = H.DocEntry
    WHERE H.CANCELED = 'N'
      AND H.DocDate < DATEADD(DAY, 1, CONVERT(date, GETDATE()))
),
Totals AS
(
    SELECT
        ItemCode,
        SUM(InQty)  AS TotalIn,
        SUM(OutQty) AS TotalOut
    FROM Movements
    GROUP BY ItemCode
),
ReceiptLayers AS
(
    -- 依入庫順序累計數量
    SELECT
        M.*,
        SUM(M.InQty) OVER
        (
            PARTITION BY M.ItemCode
            ORDER BY M.DocDate, M.DocType, M.DocEntry, M.LineNum
            ROWS UNBOUNDED PRECEDING
        ) AS CumIn
    FROM Movements M
    WHERE M.InQty > 0
),
Remaining AS
(
    -- 全部出庫量優先扣除最早的入庫層
    SELECT
        R.ItemCode,
        DATEDIFF(DAY, R.DocDate, CONVERT(date, GETDATE())) AS AgeDays,
        CASE
            WHEN T.TotalOut >= R.CumIn THEN 0
            WHEN T.TotalOut <= R.CumIn - R.InQty THEN R.InQty
            ELSE R.CumIn - T.TotalOut
        END AS RemainingQty
    FROM ReceiptLayers R
    INNER JOIN Totals T ON T.ItemCode = R.ItemCode
),
Aging AS
(
    SELECT
        ItemCode,
        SUM(RemainingQty) AS AgedQty,
        SUM(CASE WHEN AgeDays BETWEEN 0 AND 30
                 THEN RemainingQty ELSE 0 END) AS Age030,
        SUM(CASE WHEN AgeDays BETWEEN 31 AND 60
                 THEN RemainingQty ELSE 0 END) AS Age3160,
        SUM(CASE WHEN AgeDays BETWEEN 61 AND 90
                 THEN RemainingQty ELSE 0 END) AS Age6190,
        SUM(CASE WHEN AgeDays BETWEEN 91 AND 180
                 THEN RemainingQty ELSE 0 END) AS Age91180,
        SUM(CASE WHEN AgeDays BETWEEN 181 AND 365
                 THEN RemainingQty ELSE 0 END) AS Age181365,
        SUM(CASE WHEN AgeDays > 365
                 THEN RemainingQty ELSE 0 END) AS AgeOver365
    FROM Remaining
    GROUP BY ItemCode
)
SELECT
    I.ItemCode                           AS [料號],
    I.ItemName                           AS [品名],
    I.InvntryUom                         AS [庫存單位],
    I.OnHand                             AS [SAP目前庫存],
    ISNULL(T.TotalIn, 0)                  AS [指定單據累計入庫],
    ISNULL(T.TotalOut, 0)                 AS [指定單據累計出庫],
    ISNULL(T.TotalIn - T.TotalOut, 0)     AS [指定單據淨結存],
    ISNULL(A.AgedQty, 0)                 AS [已分配帳齡數量],
    I.OnHand
        - ISNULL(T.TotalIn - T.TotalOut, 0)
                                         AS [庫存核對差額],
    ISNULL(A.Age030, 0)                   AS [0至30天],
    ISNULL(A.Age3160, 0)                  AS [31至60天],
    ISNULL(A.Age6190, 0)                  AS [61至90天],
    ISNULL(A.Age91180, 0)                 AS [91至180天],
    ISNULL(A.Age181365, 0)                AS [181至365天],
    ISNULL(A.AgeOver365, 0)               AS [超過365天]
FROM OITM I
LEFT JOIN Totals T ON T.ItemCode = I.ItemCode
LEFT JOIN Aging A ON A.ItemCode = I.ItemCode
WHERE I.InvntItem = 'Y'
  AND
  (
      I.OnHand <> 0
      OR ISNULL(T.TotalIn - T.TotalOut, 0) <> 0
      OR ISNULL(A.AgedQty, 0) <> 0
  )
ORDER BY I.ItemCode
```

數量使用 `InvQty`，也就是庫存單位數量，避免採購或銷售單位不同而直接混算。[SAP 欄位說明](https://help.sap.com/doc/089315d8d0f8475a9fc84fb919b501a3/10.0/en-US/SDKHelp/SAPbobsCOM~Document_Lines~InventoryQuantity.html)
