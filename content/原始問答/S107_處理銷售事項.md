## S107-Q001｜SQL／程式碼調整與說明

日期：2026-08-24

**你的提問**

SELECT T0.[U_SALETYPE], T0.[U_CustOrderNo], T1.[U_FINALPRICETEST] FROM ORDR T0  INNER JOIN RDR1 T1 ON T0.[DocEntry] = T1.[DocEntry]

這幾個欄位 要寫SP卡控必填

**當時回答**

可放在 SAP Business One 的 `SBO_SP_TransactionNotification` 中，針對銷售訂單新增或更新進行必填卡控：

```sql
/* 銷售訂單必填欄位卡控 */
IF @object_type = '17'
   AND @transaction_type IN ('A', 'U')
BEGIN
    /* 表頭：銷售類型 */
    IF EXISTS (
        SELECT 1
        FROM ORDR T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND ISNULL(LTRIM(RTRIM(T0.U_SALETYPE)), '') = ''
    )
    BEGIN
        SET @error = -1001
        SET @error_message = N'銷售類型為必填欄位，請輸入後再儲存！'
    END

    /* 表頭：客戶訂單號碼 */
    ELSE IF EXISTS (
        SELECT 1
        FROM ORDR T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND ISNULL(LTRIM(RTRIM(T0.U_CustOrderNo)), '') = ''
    )
    BEGIN
        SET @error = -1002
        SET @error_message = N'客戶訂單號碼為必填欄位，請輸入後再儲存！'
    END

    /* 明細：最終價格測試 */
    ELSE IF EXISTS (
        SELECT 1
        FROM RDR1 T1
        WHERE T1.DocEntry = @list_of_cols_val_tab_del
          AND T1.U_FINALPRICETEST IS NULL
    )
    BEGIN
        SET @error = -1003
        SET @error_message = N'銷售訂單明細的最終價格為必填欄位，請確認每一筆明細！'
    END
END
```

如果 `U_FINALPRICETEST` 是數值欄位，而且「0」也要視為未填，條件改成：

```sql
AND ISNULL(T1.U_FINALPRICETEST, 0) = 0
```

若是文字欄位，則改成：

```sql
AND ISNULL(LTRIM(RTRIM(T1.U_FINALPRICETEST)), '') = ''
```

這段應放在 SP 最後輸出 `SELECT @error, @error_message` 之前。

## S107-Q002｜草稿也要

日期：2026-08-24

**你的提問**

草稿也要

**當時回答**

草稿物件代碼是 `112`，需再判斷 `ODRF.ObjType = '17'`，確保只卡銷售訂單草稿。

```sql
/* 銷售訂單草稿必填欄位卡控 */
IF @object_type = '112'
   AND @transaction_type IN ('A', 'U')
   AND EXISTS (
       SELECT 1
       FROM ODRF
       WHERE DocEntry = @list_of_cols_val_tab_del
         AND ObjType = '17'
   )
BEGIN
    /* 表頭：銷售類型 */
    IF EXISTS (
        SELECT 1
        FROM ODRF T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND T0.ObjType = '17'
          AND ISNULL(LTRIM(RTRIM(T0.U_SALETYPE)), '') = ''
    )
    BEGIN
        SET @error = -1011
        SET @error_message = N'銷售類型為必填欄位，請輸入後再儲存草稿！'
    END

    /* 表頭：客戶訂單號碼 */
    ELSE IF EXISTS (
        SELECT 1
        FROM ODRF T0
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND T0.ObjType = '17'
          AND ISNULL(LTRIM(RTRIM(T0.U_CustOrderNo)), '') = ''
    )
    BEGIN
        SET @error = -1012
        SET @error_message = N'客戶訂單號碼為必填欄位，請輸入後再儲存草稿！'
    END

    /* 明細：最終價格 */
    ELSE IF EXISTS (
        SELECT 1
        FROM DRF1 T1
        INNER JOIN ODRF T0
            ON T0.DocEntry = T1.DocEntry
        WHERE T0.DocEntry = @list_of_cols_val_tab_del
          AND T0.ObjType = '17'
          AND T1.U_FINALPRICETEST IS NULL
    )
    BEGIN
        SET @error = -1013
        SET @error_message = N'銷售訂單草稿明細的最終價格為必填欄位，請確認每一筆明細！'
    END
END
```

正式單與草稿都要卡控時，將這段接在前一段正式銷售訂單 `@object_type = '17'` 的程式後面即可。

如果 `U_FINALPRICETEST` 為數值欄位，且 `0` 也視為未填，使用：

```sql
AND ISNULL(T1.U_FINALPRICETEST, 0) = 0
```
