## S105-Q001｜我的銷售訂單的表頭ORDR U\_SALEPRICE 乘 表身 RDR1 FINALPRICETEST 然後要帶入到 RDR1 PriceBefDi

日期：2026-08-24

**你的提問**

我的銷售訂單的表頭ORDR U\_SALEPRICE  乘 表身 RDR1  FINALPRICETEST  然後要帶入到 RDR1 PriceBefDi

**當時回答**

在 SAP Business One 的銷售訂單中，可以把「格式化搜尋（FMS）」綁定到表身的 `PriceBefDi`（折扣前單價），計算公式為：

```text
ORDR.U_SALEPRICE × RDR1.U_FINALPRICETEST
```

如果是 SAP HANA：

```sql
SELECT
    IFNULL($[ORDR.U_SALEPRICE.NUMBER], 0)
    * IFNULL($[RDR1.U_FINALPRICETEST.NUMBER], 0)
FROM DUMMY;
```

如果是 SQL Server：

```sql
SELECT
    ISNULL($[ORDR.U_SALEPRICE.NUMBER], 0)
    * ISNULL($[RDR1.U_FINALPRICETEST.NUMBER], 0);
```

把這個查詢指定到銷售訂單表身的「折扣前單價／PriceBefDi」欄位，並設定在欄位變動時自動更新。

如果你的實際欄位名稱確實是 `FINALPRICETEST`，而不是使用者自訂欄位 `U_FINALPRICETEST`，則改成：

```sql
$[RDR1.FINALPRICETEST.NUMBER]
```

注意：若 `U_SALEPRICE` 儲存的是百分比，例如 `120` 代表 120%，公式需改為：

```sql
$[ORDR.U_SALEPRICE.NUMBER] / 100
* $[RDR1.U_FINALPRICETEST.NUMBER]
```

另外，若系統不允許 FMS 直接寫入 `PriceBefDi`，就需要使用 UI API、Transaction Notification 或其他外掛方式處理；其中 Transaction Notification 不適合直接更新同一張訂單。

## S105-Q002｜ORDR U\_SALEPRICE 這個如果是 char的話

日期：2026-08-24

**你的提問**

ORDR U\_SALEPRICE    這個如果是  char的話

**當時回答**

如果 `ORDR.U_SALEPRICE` 是字元欄位，必須先轉成數字才能相乘。

SAP HANA：

```sql
SELECT
    IFNULL(
        TO_DECIMAL(
            NULLIF(REPLACE(REPLACE($[ORDR.U_SALEPRICE], ',', ''), '%', ''), ''),
            19,
            6
        ),
        0
    )
    *
    IFNULL($[RDR1.U_FINALPRICETEST.NUMBER], 0)
FROM DUMMY;
```

SQL Server：

```sql
SELECT
    ISNULL(
        TRY_CONVERT(
            DECIMAL(19, 6),
            NULLIF(
                REPLACE(REPLACE($[ORDR.U_SALEPRICE], ',', ''), '%', ''),
                ''
            )
        ),
        0
    )
    *
    ISNULL($[RDR1.U_FINALPRICETEST.NUMBER], 0);
```

若 `U_SALEPRICE` 的內容是百分比，例如字串 `"120%"` 表示 `1.2` 倍，則需要再除以 `100`：

```sql
-- HANA
SELECT
    (
        IFNULL(
            TO_DECIMAL(
                NULLIF(REPLACE(REPLACE($[ORDR.U_SALEPRICE], ',', ''), '%', ''), ''),
                19,
                6
            ),
            0
        ) / 100
    )
    * IFNULL($[RDR1.U_FINALPRICETEST.NUMBER], 0)
FROM DUMMY;
```

如果字串是 `"1.2"`，代表直接乘以 `1.2`，就不需要除以 `100`。
