## S062-Q001｜SAPB1 薪資怎麼立帳

日期：2026-08-10

**你的提問**

SAPB1 薪資怎麼立帳

**當時回答**

在 SAP Business One 裡，薪資通常不是開 A/P 發票，而是月底用「手動日記帳分錄」立帳，再於發薪、繳稅及繳勞健保時沖帳。

假設：

- 薪資總額：100,000
- 員工自付勞健保：5,000
- 扣繳稅款：3,000
- 實發薪資：92,000
- 公司負擔勞健保、勞退：15,000

月底立帳：

| 科目 | 借方 | 貸方 |
|---|---:|---:|
| 薪資費用 | 100,000 | |
| 勞健保／退休金費用－公司負擔 | 15,000 | |
| 應付薪資 | | 92,000 |
| 應付薪資扣繳稅款 | | 3,000 |
| 應付勞健保／勞退 | | 20,000 |

其中「應付勞健保／勞退」20,000＝員工負擔5,000＋公司負擔15,000。

發薪時：

| 科目 | 借方 | 貸方 |
|---|---:|---:|
| 應付薪資 | 92,000 | |
| 銀行存款 | | 92,000 |

繳交扣繳稅款時：

- 借：應付薪資扣繳稅款
- 貸：銀行存款

繳交勞健保與勞退時：

- 借：應付勞健保／勞退
- 貸：銀行存款

SAP B1 操作路徑：

`財務 → 日記帳分錄`

建議設定：

- 過帳日期：薪資所屬月份月底
- 到期日：預計發薪日
- 備註：例如「2026年7月薪資立帳」
- 交易代碼：可建立 `PAYROLL`
- 各費用列帶入部門、成本中心或分攤規則
- 將薪資表、銀行轉帳清冊作為附件
- 限制薪資分錄及附件的查看權限

如果每月科目結構固定，可使用：

`財務 → 週期性過帳`

建立薪資分錄範本，每月只修改金額後執行。SAP 官方也將 payroll 列為週期性過帳的使用情境；正式日記帳不能直接刪除，錯誤時需以沖銷／更正分錄處理。[SAP：Journal Entry](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/451149f829fc4805e10000000a1553f6.html) [SAP：Recurring Posting](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/451148b729fc4805e10000000a1553f6.html)

實際科目名稱與勞健保、勞退拆分方式，仍應依公司的會計科目表及會計師政策設定。

## S062-Q003｜是甚麼科目

日期：2026-08-10

**你的提問**

是甚麼科目

**當時回答**

「關係人勞務收入」是**損益表的收入科目**，通常歸在：

- 營業收入－勞務收入－關係人
- 科目性質：收入類
- SAP B1 科目類型：Sales／銷售收入
- 正常餘額：貸方

例如公司向關係企業收取服務費 100,000 元（未稅）：

| 科目 | 借方 | 貸方 |
|---|---:|---:|
| 應收帳款－關係人 | 105,000 | |
| 關係人勞務收入 | | 100,000 |
| 銷項稅額 | | 5,000 |

SAP B1 通常應開：

`銷售 → A/R 發票`

客戶主檔設為該關係企業，收入科目指定為「關係人勞務收入」。

如果你是**付錢給關係人**，就不是此科目，而應使用「關係人勞務費／勞務成本」及「應付關係人款項」。

## S062-Q004｜那是甚麼意思

日期：2026-08-10

**你的提問**

那是甚麼意思

**當時回答**

「關係人勞務收入」的意思是：

**公司替與自己有特殊關係的個人或公司提供服務，因此收到或應收的收入。**

例如甲公司替同一集團的乙公司提供：

- 管理服務
- 人力支援
- 資訊服務
- 顧問服務
- 技術支援

甲公司向乙公司收取 10 萬元，甲公司就會記：

- 借：應收帳款－關係人 105,000
- 貸：關係人勞務收入 100,000
- 貸：銷項稅額 5,000

「關係人」通常包括母子公司、同集團公司、具有控制關係的公司、主要股東或董監事等；「勞務收入」就是提供服務所賺到的錢。

簡單說：**服務對象是關係人，所以把這筆服務收入獨立標示出來。**它不是薪資，也不是公司付出去的勞務費。

## S062-Q005｜退關稅的話 在營業外科目嗎

日期：2026-08-10

**你的提問**

退關稅的話 在營業外科目嗎

**當時回答**

通常不是直接列「營業外收入」。

退回的關稅原則上應沖減原先負擔關稅的科目：

- 貨物尚未出售：沖減「存貨成本」
- 貨物已出售：沖減「銷貨成本」
- 原關稅列為費用：沖減原費用科目
- 無法追溯、跨年度且金額不重大：才可能列「其他收入／其他利益」，是否屬營業外依公司會計政策決定

例如收到關稅退稅 50,000 元，貨物已出售：

| 科目 | 借方 | 貸方 |
|---|---:|---:|
| 銀行存款／其他應收款 | 50,000 | |
| 銷貨成本－關稅退回 | | 50,000 |

若貨物仍在庫：

- 借：銀行存款／其他應收款
- 貸：存貨

另外要區分：

- **關稅退回**：通常調整存貨或銷貨成本
- **進口營業稅退回**：通常沖「進項稅額／應收退稅款」，不是收入
- **政府補助或獎勵款**：才較可能列其他收入

所以在 SAP B1 建議不要預設放「營業外收入」，先看當初進口關稅被記在哪個科目，再沖回該科目。
