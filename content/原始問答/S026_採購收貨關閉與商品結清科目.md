## S026-Q002｜這個表格代表甚麼 sapb1

日期：2026-07-27

**你的提問**

這個表格代表甚麼 sapb1

**當時回答**

這是 SAP Business One 的「總帳科目決定 → 存貨」設定表。

它的用途是：當使用者操作收貨、出貨、銷售、退貨、存貨重估或生產等交易時，SAP B1 根據這張表，自動決定會計分錄要過到哪些總帳科目。它不是庫存明細表，而是「自動分錄的科目對照設定」。

畫面中的主要欄位：

| 科目類型 | 畫面設定 | 用途 |
|---|---:|---|
| 存貨科目 | 1170 | 記錄庫存資產價值；收貨通常借記、出貨通常貸記 |
| 銷貨成本 | 5121 | 商品銷售出庫時，記錄銷貨成本 |
| 分配科目 | 1550 | 採購收貨暫估／過渡科目，連接採購收貨與應付發票 |
| 差異科目 | 空白 | 主要用於標準成本與實際採購價格的差異 |
| 價格差異科目 | 9114 | 採購基礎單據與後續單據價格不同時使用 |
| 負存貨調整科目 | 空白 | 負庫存補回時，處理成本差異 |
| 存貨餘額－減少科目 | 9134 | 存貨重估造成價值減少時使用 |
| 存貨餘額－增加科目 | 9114 | 存貨重估造成價值增加時使用 |
| 銷售退貨科目 | 4211 | 特定銷售退貨情境下使用 |
| 匯率差異科目 | 9112 | 採購單據使用外幣、匯率不同所產生的差額 |
| 商品結清科目 | 空白 | 結清採購收貨或退貨時，若不再調整庫存價值，用來承接差額 |
| 總帳減少／增加科目 | 空白 | 存貨重估所需的平衡科目 |
| 在製品存貨科目 | 空白 | 生產過程中的在製品價值 |
| 在製品存貨差異科目 | 空白 | 生產投入與完工之間的成本差異 |
| 在製品沖銷損益科目 | 空白 | 特定生產結清或沖銷差異使用 |
| 存貨餘額損益科目 | 空白 | 特定存貨價值差異的損益科目 |
| 費用結清科目 | 空白 | 採購附加費用影響存貨價值時的對應科目 |

簡單例子：

1. 銷售商品出庫，成本為 1,000：

```text
借：銷貨成本 5121       1,000
貸：存貨科目 1170       1,000
```

2. 採購收貨，金額為 1,000：

```text
借：存貨科目 1170       1,000
貸：分配科目 1550       1,000
```

3. 後續建立應付發票時：

```text
借：分配科目 1550       1,000
貸：供應商統馭科目      1,000
```

因此，1550 通常是「收貨未開發票」的暫估科目；其餘額通常代表尚未被應付發票結清的採購收貨。

另外需要注意：

- 畫面選的是 2026 期間，表示這組設定適用於該過帳期間。
- 黃色箭頭可開啟對應的總帳科目資料。
- 這裡通常是預設科目；實際過帳科目可能被倉庫、物料群組、物料主檔或進階科目決定規則覆蓋。
- 空白欄位不一定全部都要填，是否需要取決於存貨計價法、生產功能、負庫存、外幣採購及公司的啟用設定。
- 已經正式使用後不要任意更換科目，否則可能造成存貨稽核報表與總帳不一致。SAP 官方也特別提醒，變更此處可能導致錯誤的存貨交易。

參考：[SAP Business One 10.0－G/L Account Determination: Inventory Tab](https://help.sap.com/docs/SAP_BUSINESS_ONE/68a2e87fb29941b5bf959a184d9c6727/4506b8ab7d720487e10000000a155369.html)

## S026-Q003｜如果我是要把收貨採購單關閉呢

日期：2026-07-27

**你的提問**

如果我是要把收貨採購單關閉呢

**當時回答**

如果你要在 SAP B1 把「收貨採購單（Goods Receipt PO）」直接關閉，而不再建立應付發票，畫面中的「商品結清科目」就是會用到的科目。

關閉時，SAP B1 的處理是：

- 不會退回或減少庫存。
- 收貨產生的庫存數量與存貨價值仍然保留。
- 單據狀態改成「已關閉」，之後不能再複製到應付發票。
- 系統會產生結清分錄，把尚未結清的「分配科目」轉到「商品結清科目」。

依你圖片中的設定，假設未開票金額為 10,000，基本分錄概念為：

```text
借：1550 分配科目／暫估應付款       10,000
貸：商品結清科目                  10,000
```

所以你圖片中空白的「商品結清科目」應先設定。如果未設定，關閉收貨採購單時可能會出現「缺少總帳科目」之類的錯誤。

「商品結清科目」建議設定為一個專用損益科目，例如：

```text
未開票採購結清損益
收貨未開票沖銷
GRPO Closing Clearing
```

不要直接使用 1170 存貨科目，因為關閉收貨採購單本身不應再次改變存貨價值。實際應歸類為費用、其他收益或專用結清損益，需由公司的會計政策決定。

特別注意：如果是以下情況，不應使用「關閉」：

- 貨物實際沒有收到或需要退出：建立「採購退貨」。
- 收貨單輸入錯誤，需要整筆撤銷：符合條件時使用「取消」。
- 供應商之後仍會開發票：應保留收貨採購單，再複製到「應付發票」。

「關閉」適合的情況是：貨確實已入庫，但確定不會再收到供應商發票，或只需結清尚未開票的剩餘部分。

另外，SAP 官方說明關閉動作不可逆，執行時系統通常會要求選擇結清分錄的過帳日期。若公司啟用了「採購科目過帳系統」，分錄還可能同時包含採購科目，但核心仍是用「商品結清科目」清掉未結的分配科目。[SAP 官方說明](https://help.sap.com/docs/SAP_BUSINESS_ONE/87e1767ca7584b8f8d60775347637b07/f8b65bce9dcf4ea9a4f71b334e4ff4da.html)

## S026-Q005｜找不到相符的記錄 '總帳科目' (OACT) (ODBC -2028) [訊息 131-183] 我要關閉收貨採購 跳出這個

日期：2026-07-27

**你的提問**

## My request for Codex:
找不到相符的記錄  '總帳科目' (OACT) (ODBC -2028)  [訊息 131-183] 
我要關閉收貨採購 跳出這個

**當時回答**

這個錯誤表示：SAP B1 關閉收貨採購單、準備產生結清分錄時，找不到所需的總帳科目。

依你提供的畫面，最可能原因就是「商品結清科目」目前空白。

請這樣處理：

1. 進入「管理 → 設定 → 財務 → 總帳科目決定」。
2. 選擇關閉分錄所屬期間，例如 2026。
3. 進入「存貨」頁籤。
4. 在「商品結清科目」選擇一個有效的過帳科目。
5. 按「確定／更新」儲存。
6. 重新開啟收貨採購單，再執行「關閉」。

科目必須符合以下條件：

- 是明細／可過帳科目，不能是標題科目。
- 科目存在於總帳科目表 OACT。
- 科目沒有被鎖定或停用。
- 適用於關閉分錄的過帳日期。
- 若交易包含外幣，建議科目貨幣設定為「所有貨幣」。

關閉時通常會產生類似分錄：

```text
借：1550 分配科目
貸：商品結清科目
```

如果設定「商品結清科目」後仍出現相同錯誤，再檢查：

- 收貨採購單是否包含運費：可能還缺「費用結清科目」。
- 是否啟用了進階總帳科目決定：倉庫、物料群組或物料規則可能指定了已刪除或無效科目。
- 關閉分錄選擇的過帳日期是否屬於另一個期間；例如選到 2025，就要檢查 2025 的科目決定。
- 1550「分配科目」本身是否仍為有效的可過帳科目。
- 若公司啟用了「採購科目過帳系統」，也要確認採購科目、購入商品成本科目及採購餘額科目均有效。

因此，第一步先補上你畫面反白的「商品結清科目」。如果這張收貨採購單有運費，最好也同時補上最下方的「費用結清科目」。

## S026-Q006｜通常 商品結清科目

日期：2026-07-27

**你的提問**

## My request for Codex:
通常 商品結清科目

**當時回答**

「商品結清科目」通常設定為一個專用的損益類科目，用來承接「收貨後不再開應付發票」的金額。

建議科目名稱：

```text
收貨採購結清差異
收貨未開票結清損益
採購暫估結清差異
GRPO Closing Difference
```

科目性質通常為：

- 損益類明細科目
- 可直接過帳
- 貨幣設定為「所有貨幣」
- 借貸兩方都允許使用

若關閉已收貨但未開票的收貨採購單，通常是：

```text
借：1550 暫估／分配科目
貸：商品結清科目
```

所以這筆金額在多數情況會表現為「其他收入或採購結清利益」。但同一科目也可能因採購退貨結清而出現在借方，因此最好建立獨立的「結清差異」損益科目，而不是直接放入一般營業收入。

不建議使用：

- 1170 存貨科目
- 1550 分配科目
- 5121 銷貨成本
- 9114 存貨盤盈，除非公司會計政策明確規定
- 供應商統馭科目

以你目前的科目編碼結構來看，可以請會計在 91xx 損益類下面新增，例如：

```text
91xx　收貨未開票結清損益
越文：Chênh lệch tất toán hàng nhận chưa hóa đơn
英文：GRPO Closing Difference
```

若金額重大，建議先確認為什麼「已收到貨但不用付款」；正常有供應商發票的收貨採購單，應建立應付發票結清 1550，而不是直接關閉。
