## S061-Q001｜我想寫查詢報表關於： OPOR,POR1 然後我想用採購的物料或是 業務夥伴做搜尋

日期：2026-08-10

**你的提問**

我想寫查詢報表關於：
OPOR,POR1  然後我想用採購的物料或是 業務夥伴做搜尋

**當時回答**

以下是 SAP Business One SQL Server 版查詢，可從 `OPOR`（採購訂單表頭）及 `POR1`（採購訂單明細）依「物料」或「業務夥伴」搜尋。兩個條件都可留空；若同時輸入，則會同時篩選。

```sql
/* SAP Business One－採購訂單查詢 */

DECLARE @ItemCode NVARCHAR(100)
DECLARE @CardCode NVARCHAR(100)

SET @ItemCode = /* SELECT T0.ItemCode FROM OITM T0 WHERE T0.ItemCode */ '[%0]'
SET @CardCode = /* SELECT T0.CardCode FROM OCRD T0 WHERE T0.CardType = 'S' */ '[%1]'

SELECT
    T0.DocNum                         AS N'採購單號',
    T0.DocDate                        AS N'過帳日期',
    T0.DocDueDate                     AS N'交貨日期',
    T0.CardCode                       AS N'供應商代碼',
    T0.CardName                       AS N'供應商名稱',
    T1.LineNum + 1                    AS N'列號',
    T1.ItemCode                       AS N'物料號碼',
    T1.Dscription                     AS N'物料說明',
    T1.Quantity                       AS N'訂購數量',
    T1.OpenQty                        AS N'未交數量',
    T1.Price                          AS N'單價',
    T1.LineTotal                      AS N'未稅金額',
    T0.DocCur                         AS N'幣別',
    T1.WhsCode                        AS N'倉庫',
    CASE T0.DocStatus
        WHEN 'O' THEN N'未結'
        WHEN 'C' THEN N'已結'
    END                               AS N'文件狀態',
    CASE T1.LineStatus
        WHEN 'O' THEN N'未結'
        WHEN 'C' THEN N'已結'
    END                               AS N'明細狀態',
    T0.NumAtCard                      AS N'供應商參考號碼',
    T0.Comments                       AS N'備註'
FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry
WHERE
    T0.CANCELED = 'N'
    AND (
        ISNULL(@ItemCode, '') = ''
        OR T1.ItemCode LIKE '%' + @ItemCode + '%'
        OR T1.Dscription LIKE '%' + @ItemCode + '%'
    )
    AND (
        ISNULL(@CardCode, '') = ''
        OR T0.CardCode LIKE '%' + @CardCode + '%'
        OR T0.CardName LIKE '%' + @CardCode + '%'
    )
ORDER BY
    T0.DocDate DESC,
    T0.DocNum DESC,
    T1.LineNum
```

查詢時：

- `[%0]`：可輸入物料號碼或物料說明，留空代表全部物料。
- `[%1]`：可輸入供應商代碼或名稱，留空代表全部供應商。
- 同時輸入物料與供應商時，會查出符合兩項條件的採購訂單。
- 查詢已排除取消的採購訂單。

如果資料庫是 SAP HANA，語法會不同，以上版本適用於 Microsoft SQL Server。

## S061-Q002｜FMS 沒辦用DECLARE

日期：2026-08-10

**你的提問**

FMS 沒辦用DECLARE

**當時回答**

對，SAP Business One 的「格式化搜尋（FMS）」不能使用 `DECLARE`，需要直接使用畫面欄位變數。

如果是在採購訂單畫面：

- `$[$4.0.0]`：目前畫面的供應商代碼
- `$[$38.1.0]`：目前選取列的物料號碼

可改成：

```sql
SELECT
    T0.DocNum,
    T0.DocDate,
    T0.CardCode,
    T0.CardName,
    T1.ItemCode,
    T1.Dscription,
    T1.Quantity,
    T1.OpenQty,
    T1.Price,
    T1.LineTotal
FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry
WHERE T0.CANCELED = 'N'
  AND (
        T0.CardCode = $[$4.0.0]
        OR T1.ItemCode = $[$38.1.0]
      )
ORDER BY T0.DocDate DESC, T0.DocNum DESC
```

但要注意：FMS 通常只能把「單一結果值」帶回一個欄位，並不適合顯示多欄、多筆的查詢報表。上面的查詢比較適合透過「查詢管理員」執行。

如果你的需求是在查詢管理員內讓使用者輸入物料或供應商，但不能使用 `DECLARE`，可以直接這樣寫：

```sql
SELECT
    T0.DocNum                         AS N'採購單號',
    T0.DocDate                        AS N'過帳日期',
    T0.DocDueDate                     AS N'交貨日期',
    T0.CardCode                       AS N'供應商代碼',
    T0.CardName                       AS N'供應商名稱',
    T1.LineNum + 1                    AS N'列號',
    T1.ItemCode                       AS N'物料號碼',
    T1.Dscription                     AS N'物料說明',
    T1.Quantity                       AS N'訂購數量',
    T1.OpenQty                        AS N'未交數量',
    T1.Price                          AS N'單價',
    T1.LineTotal                      AS N'未稅金額',
    T1.WhsCode                        AS N'倉庫',
    CASE T0.DocStatus
        WHEN 'O' THEN N'未結'
        WHEN 'C' THEN N'已結'
    END                               AS N'文件狀態'
FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry
WHERE T0.CANCELED = 'N'
  AND (
        '[%0]' = ''
        OR T1.ItemCode LIKE '%[%0]%'
        OR T1.Dscription LIKE '%[%0]%'
      )
  AND (
        '[%1]' = ''
        OR T0.CardCode LIKE '%[%1]%'
        OR T0.CardName LIKE '%[%1]%'
      )
ORDER BY T0.DocDate DESC, T0.DocNum DESC, T1.LineNum
```

其中 `[%0]` 是物料條件、`[%1]` 是供應商條件，皆可留空。真正的 FMS 則要依「目前畫面欄位」搜尋，不能跳出 `[%0]`、`[%1]` 輸入視窗。

## S061-Q003｜我變成要篩選是否為取消單據，我想要不要篩選是否為篩選單據，以及我搜尋出來都是沒有結果

日期：2026-08-10

**你的提問**

我變成要篩選是否為取消單據，我想要不要篩選是否為篩選單據，以及我搜尋出來都是沒有結果

**當時回答**

沒有結果的主要原因可能是 `LIKE '%[%0]%'` 的參數組合方式。SAP B1 SQL Server 建議使用字串串接。另外，`OPOR.CANCELED`：

- `N`：未取消
- `Y`：已取消
- 留空：全部單據

以下版本不使用 `DECLARE`：

```sql
SELECT
    T0.DocNum                         AS N'採購單號',
    T0.DocDate                        AS N'過帳日期',
    T0.DocDueDate                     AS N'交貨日期',
    T0.CardCode                       AS N'供應商代碼',
    T0.CardName                       AS N'供應商名稱',
    T1.LineNum + 1                    AS N'列號',
    T1.ItemCode                       AS N'物料號碼',
    T1.Dscription                     AS N'物料說明',
    T1.Quantity                       AS N'訂購數量',
    T1.OpenQty                        AS N'未交數量',
    T1.Price                          AS N'單價',
    T1.LineTotal                      AS N'未稅金額',
    T1.WhsCode                        AS N'倉庫',
    CASE T0.CANCELED
        WHEN 'N' THEN N'未取消'
        WHEN 'Y' THEN N'已取消'
    END                               AS N'取消狀態',
    CASE T0.DocStatus
        WHEN 'O' THEN N'未結'
        WHEN 'C' THEN N'已結'
    END                               AS N'文件狀態'
FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry
WHERE
    (
        '[%0]' = ''
        OR T1.ItemCode LIKE N'%' + '[%0]' + N'%'
        OR T1.Dscription LIKE N'%' + '[%0]' + N'%'
    )
    AND
    (
        '[%1]' = ''
        OR T0.CardCode LIKE N'%' + '[%1]' + N'%'
        OR T0.CardName LIKE N'%' + '[%1]' + N'%'
    )
    AND
    (
        '[%2]' = ''
        OR T0.CANCELED = '[%2]'
    )
ORDER BY
    T0.DocDate DESC,
    T0.DocNum DESC,
    T1.LineNum
```

輸入方式：

1. `[%0]`：物料號碼或物料說明；不限制就留空。
2. `[%1]`：供應商代碼或供應商名稱；不限制就留空。
3. `[%2]`：取消狀態：
   - 輸入 `N`：只看未取消
   - 輸入 `Y`：只看已取消
   - 留空：取消與未取消都顯示

先測試時，三個條件全部留空，應該會列出所有採購訂單。如果仍然完全沒有資料，先執行這個最小測試：

```sql
SELECT TOP 100
    T0.DocNum,
    T0.CardCode,
    T0.CardName,
    T0.CANCELED,
    T1.ItemCode,
    T1.Dscription
FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry
ORDER BY T0.DocEntry DESC
```

如果最小測試有資料，代表問題是在參數篩選；如果沒有資料，則要確認目前登入的公司資料庫是否確實有採購訂單。

另外，如果你執行的位置真的是「格式化搜尋 FMS」，而不是「查詢管理員」，`[%0]` 這類人工輸入參數不適用；FMS 必須改用 `$[$欄位UID.欄位.類型]` 讀取畫面欄位。

## S061-Q004｜如果我三個為空值 是有資料

日期：2026-08-10

**你的提問**

如果我三個為空值 是有資料

**當時回答**

這表示資料表與 JOIN 都正常，問題是在「輸入值與篩選條件不相符」。

特別注意取消狀態不能輸入「是／否」或「已取消／未取消」，原查詢只能輸入資料庫代碼：

- `N`：未取消
- `Y`：原單據已取消
- `C`：取消單據（部分 SAP B1 版本會出現）
- 空白：全部

建議把條件改成可接受中文，並清除前後空白：

```sql
AND (
       LTRIM(RTRIM('[%2]')) IN ('', N'全部', 'A')
    OR (
           LTRIM(RTRIM('[%2]')) IN ('N', N'未取消')
       AND T0.CANCELED = 'N'
    )
    OR (
           LTRIM(RTRIM('[%2]')) IN ('Y', N'已取消')
       AND T0.CANCELED = 'Y'
    )
    OR (
           LTRIM(RTRIM('[%2]')) IN ('C', N'取消單據')
       AND T0.CANCELED = 'C'
    )
)
```

完整的 `WHERE` 可改成：

```sql
WHERE
    (
        LTRIM(RTRIM('[%0]')) = ''
        OR ISNULL(T1.ItemCode, '') LIKE N'%' + LTRIM(RTRIM('[%0]')) + N'%'
        OR ISNULL(T1.Dscription, '') LIKE N'%' + LTRIM(RTRIM('[%0]')) + N'%'
    )
    AND
    (
        LTRIM(RTRIM('[%1]')) = ''
        OR ISNULL(T0.CardCode, '') LIKE N'%' + LTRIM(RTRIM('[%1]')) + N'%'
        OR ISNULL(T0.CardName, '') LIKE N'%' + LTRIM(RTRIM('[%1]')) + N'%'
    )
    AND
    (
           LTRIM(RTRIM('[%2]')) IN ('', N'全部', 'A')
        OR (
               LTRIM(RTRIM('[%2]')) IN ('N', N'未取消')
           AND T0.CANCELED = 'N'
        )
        OR (
               LTRIM(RTRIM('[%2]')) IN ('Y', N'已取消')
           AND T0.CANCELED = 'Y'
        )
        OR (
               LTRIM(RTRIM('[%2]')) IN ('C', N'取消單據')
           AND T0.CANCELED = 'C'
        )
    )
```

測試時依序進行：

1. 只輸入物料，其他留空。
2. 只輸入供應商，其他留空。
3. 前兩個留空，取消狀態輸入 `N`。
4. 前兩個留空，取消狀態輸入 `Y`。

另外，物料與供應商之間目前使用 `AND`。如果兩個都有輸入，代表必須是「這個供應商的這個物料」才會顯示；不是任一條件符合就顯示。

## S061-Q005｜但只要有填資料進去 就會沒有資料

日期：2026-08-10

**你的提問**

但只要有填資料進去 就會沒有資料

**當時回答**

既然三個空白有資料，但任何欄位一輸入就沒有，表示 SAP B1 傳入的參數值可能不是我們預期的內容。先不要繼續改主查詢，請執行以下診斷查詢：

```sql
SELECT
    N'>' + '[%0]' + N'<' AS N'物料輸入值',
    LEN('[%0]')           AS N'物料字數',
    N'>' + '[%1]' + N'<' AS N'供應商輸入值',
    LEN('[%1]')           AS N'供應商字數',
    N'>' + '[%2]' + N'<' AS N'取消狀態輸入值',
    LEN('[%2]')           AS N'狀態字數'
```

例如只在第一個欄位輸入一個確定存在的物料號碼，看看查詢結果顯示什麼。

也可以用下面這個最簡單版本分別測試。

物料測試：

```sql
SELECT TOP 100
    T1.ItemCode,
    T1.Dscription,
    T0.DocNum
FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry
WHERE T1.ItemCode = '[%0]'
```

供應商測試：

```sql
SELECT TOP 100
    T0.CardCode,
    T0.CardName,
    T0.DocNum
FROM OPOR T0
WHERE T0.CardCode = '[%0]'
```

取消狀態測試：

```sql
SELECT
    T0.CANCELED,
    COUNT(*) AS N'單據數量'
FROM OPOR T0
GROUP BY T0.CANCELED
```

最後一個查詢不需要輸入參數，可以確認你的資料庫實際存在的狀態，例如：

| CANCELED | 意義 |
|---|---|
| N | 未取消 |
| Y | 已取消 |
| C | 取消單據 |

另外有一個關鍵點：如果你確實是在「格式化搜尋 FMS」執行，而不是「查詢管理員」，就不能用 `[%0]`、`[%1]`、`[%2]` 作為畫面欄位值。FMS 應使用像這樣的欄位變數：

```sql
$[$4.0.0]
```

也就是目前採購訂單畫面的供應商代碼。這時「全部留空有資料、輸入後沒資料」很可能就是因為把查詢管理員參數語法用在 FMS。請把第一個診斷查詢的結果貼給我，就能確認實際傳入了什麼值。

## S061-Q006｜可以再給我一份，我想要篩選 業務主檔 或 物料

日期：2026-08-10

**你的提問**

可以再給我一份，我想要篩選 業務主檔 或 物料

**當時回答**

可以，這份改成只有一個搜尋欄位：輸入「業務夥伴代碼／名稱」或「物料號碼／說明」都可以搜尋，條件之間使用 `OR`。

適用 SAP Business One 查詢管理員、SQL Server，且不使用 `DECLARE`：

```sql
SELECT
    T0.DocNum                         AS N'採購單號',
    T0.DocDate                        AS N'過帳日期',
    T0.DocDueDate                     AS N'交貨日期',
    T0.CardCode                       AS N'業務夥伴代碼',
    T0.CardName                       AS N'業務夥伴名稱',

    T1.LineNum + 1                    AS N'列號',
    T1.ItemCode                       AS N'物料號碼',
    T1.Dscription                     AS N'物料說明',
    T1.Quantity                       AS N'訂購數量',
    T1.OpenQty                        AS N'未交數量',
    T1.Price                          AS N'單價',
    T1.LineTotal                      AS N'未稅金額',
    T1.WhsCode                        AS N'倉庫',

    CASE T0.CANCELED
        WHEN 'N' THEN N'未取消'
        WHEN 'Y' THEN N'已取消'
        WHEN 'C' THEN N'取消單據'
        ELSE T0.CANCELED
    END                               AS N'取消狀態',

    CASE T0.DocStatus
        WHEN 'O' THEN N'未結'
        WHEN 'C' THEN N'已結'
        ELSE T0.DocStatus
    END                               AS N'文件狀態'

FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry

WHERE
    (
        '[%0]' = ''
        OR T0.CardCode LIKE N'%[%0]%'
        OR T0.CardName LIKE N'%[%0]%'
        OR T1.ItemCode LIKE N'%[%0]%'
        OR T1.Dscription LIKE N'%[%0]%'
    )
    AND
    (
        '[%1]' = ''
        OR '[%1]' = N'全部'
        OR T0.CANCELED = '[%1]'
    )

ORDER BY
    T0.DocDate DESC,
    T0.DocNum DESC,
    T1.LineNum
```

輸入方式：

- `[%0]` 搜尋關鍵字：
  - 可輸入業務夥伴代碼
  - 可輸入業務夥伴名稱
  - 可輸入物料號碼
  - 可輸入物料說明
  - 留空顯示全部

- `[%1]` 取消狀態：
  - 留空或輸入「全部」：全部顯示
  - `N`：未取消
  - `Y`：已取消
  - `C`：取消單據

例如：

```text
[%0]：A0001
[%1]：N
```

代表搜尋業務夥伴或物料中包含 `A0001`，而且只顯示未取消的採購訂單。

這份是「查詢管理員」使用的查詢；若是綁定畫面欄位的格式化搜尋 FMS，則不能使用 `[%0]` 輸入視窗。

## S061-Q007｜還有其他方式嗎 這個篩選還是無法使用

日期：2026-08-10

**你的提問**

還有其他方式嗎 這個篩選還是無法使用

**當時回答**

有。你現在遇到的狀況，很可能是「格式化搜尋 FMS」不適合使用 `[%0]` 這種互動式篩選。建議改用 SAP B1「查詢管理員」，並先使用完全比對，不使用 `LIKE`。

這份查詢把業務夥伴與物料拆成兩個選擇條件：

```sql
SELECT
    T0.DocNum                         AS N'採購單號',
    T0.DocDate                        AS N'過帳日期',
    T0.DocDueDate                     AS N'交貨日期',
    T0.CardCode                       AS N'業務夥伴代碼',
    T0.CardName                       AS N'業務夥伴名稱',
    T1.LineNum + 1                    AS N'列號',
    T1.ItemCode                       AS N'物料號碼',
    T1.Dscription                     AS N'物料說明',
    T1.Quantity                       AS N'訂購數量',
    T1.OpenQty                        AS N'未交數量',
    T1.Price                          AS N'單價',
    T1.LineTotal                      AS N'未稅金額',
    T1.WhsCode                        AS N'倉庫',

    CASE T0.CANCELED
        WHEN 'N' THEN N'未取消'
        WHEN 'Y' THEN N'已取消'
        WHEN 'C' THEN N'取消單據'
        ELSE T0.CANCELED
    END                               AS N'取消狀態'

FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry

WHERE
       (
            (
                '[%0]' <> ''
                AND T0.CardCode =
                    /* SELECT T9.CardCode
                       FROM OCRD T9
                       WHERE T9.CardType = 'S' */
                    '[%0]'
            )
            OR
            (
                '[%1]' <> ''
                AND T1.ItemCode =
                    /* SELECT T8.ItemCode
                       FROM OITM T8 */
                    '[%1]'
            )
            OR
            (
                '[%0]' = ''
                AND '[%1]' = ''
            )
       )
  AND (
           '[%2]' = ''
        OR T0.CANCELED = '[%2]'
      )

ORDER BY
    T0.DocDate DESC,
    T0.DocNum DESC,
    T1.LineNum
```

參數如下：

- `[%0]`：供應商代碼，必須輸入 `CardCode`，例如 `V10001`，不要輸入供應商名稱。
- `[%1]`：物料號碼，必須輸入 `ItemCode`，不要輸入物料說明。
- `[%2]`：取消狀態，輸入 `N`、`Y` 或 `C`；留空代表全部。

這個版本的邏輯是：

- 只輸入供應商：搜尋該供應商全部物料。
- 只輸入物料：搜尋所有供應商的該物料。
- 兩者都輸入：供應商或物料任一符合就顯示。
- 兩者都留空：顯示全部。

如果希望兩者都輸入時必須同時符合，把中間的查詢邏輯改成：

```sql
WHERE
    (
        '[%0]' = ''
        OR T0.CardCode = '[%0]'
    )
    AND
    (
        '[%1]' = ''
        OR T1.ItemCode = '[%1]'
    )
    AND
    (
        '[%2]' = ''
        OR T0.CANCELED = '[%2]'
    )
```

如果你是在真正的「格式化搜尋 FMS」執行，則上述查詢仍不適用，因為：

- FMS 不會提供查詢報表的輸入條件。
- FMS 通常只能回傳一個值給目前欄位。
- 要篩選並顯示多筆 `OPOR/POR1`，應放在「工具 → 查詢 → 查詢管理員」中執行。

若一定要使用 FMS，則只能讀取目前採購訂單畫面的值，例如供應商：

```sql
SELECT TOP 1 T0.DocNum
FROM OPOR T0
WHERE T0.CardCode = $[$4.0.0]
ORDER BY T0.DocEntry DESC
```

或目前明細列的物料：

```sql
SELECT TOP 1 T0.DocNum
FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry
WHERE T1.ItemCode = $[$38.1.0]
ORDER BY T0.DocEntry DESC
```

因此，你要的是「多筆查詢報表」時，請使用查詢管理員，不要使用 FMS。

## S061-Q010｜你要寫兩個Where 一個是條件A，條件B空白 一個是條件B，條件A空白啊

日期：2026-08-10

**你的提問**

你要寫兩個Where
一個是條件A，條件B空白
一個是條件B，條件A空白啊

**當時回答**

了解，你要的是互斥條件：

- 條件 A（業務夥伴）有值時，條件 B（物料）必須空白。
- 條件 B（物料）有值時，條件 A（業務夥伴）必須空白。

同一個 `SELECT` 不能寫兩次 `WHERE`，要在 `WHERE` 裡寫兩組條件，再用 `OR` 連接：

```sql
SELECT
    T0.DocNum             AS N'採購單號',
    T0.DocDate            AS N'過帳日期',
    T0.DocDueDate         AS N'交貨日期',
    T0.CardCode           AS N'供應商代碼',
    T0.CardName           AS N'供應商名稱',
    T1.LineNum + 1        AS N'列號',
    T1.ItemCode           AS N'物料號碼',
    T1.Dscription         AS N'物料說明',
    T1.Quantity           AS N'訂購數量',
    T1.OpenQty            AS N'未交數量',
    T1.Price              AS N'單價',
    T1.LineTotal          AS N'未稅金額',
    T1.WhsCode            AS N'倉庫',

    CASE T0.CANCELED
        WHEN 'N' THEN N'未取消'
        WHEN 'Y' THEN N'已取消'
        WHEN 'C' THEN N'取消單據'
        ELSE T0.CANCELED
    END                   AS N'取消狀態'

FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry

WHERE
    (
        /* 條件A有值、條件B空白：依供應商搜尋 */
        '[%0]' <> ''
        AND '[%1]' = ''
        AND T0.CardCode = '[%0]'
    )
    OR
    (
        /* 條件B有值、條件A空白：依物料搜尋 */
        '[%1]' <> ''
        AND '[%0]' = ''
        AND T1.ItemCode = '[%1]'
    )

ORDER BY
    T0.DocDate DESC,
    T0.DocNum DESC,
    T1.LineNum
```

參數：

- `[%0]`：條件 A，供應商代碼。
- `[%1]`：條件 B，物料號碼。

使用方式：

| `[%0]` 供應商 | `[%1]` 物料 | 結果 |
|---|---|---|
| 有值 | 空白 | 依供應商搜尋 |
| 空白 | 有值 | 依物料搜尋 |
| 有值 | 有值 | 不顯示資料 |
| 空白 | 空白 | 不顯示資料 |

如果希望兩個都空白時顯示全部，再於 `WHERE` 最後加入：

```sql
    OR
    (
        '[%0]' = ''
        AND '[%1]' = ''
    )
```

如果要模糊搜尋，把兩個完全比對條件改成：

```sql
AND (
       T0.CardCode LIKE N'%[%0]%'
    OR T0.CardName LIKE N'%[%0]%'
)
```

以及：

```sql
AND (
       T1.ItemCode LIKE N'%[%1]%'
    OR T1.Dscription LIKE N'%[%1]%'
)
```

## S061-Q011｜還是不行欸

日期：2026-08-10

**你的提問**

還是不行欸

**當時回答**

那就照你的意思，直接用 `UNION ALL` 寫成兩個完整的 `WHERE`，不把條件混在同一個 `WHERE` 裡。

```sql
/* 條件A：依業務夥伴查詢，物料條件必須空白 */

SELECT
    T0.DocNum             AS N'採購單號',
    T0.DocDate            AS N'過帳日期',
    T0.DocDueDate         AS N'交貨日期',
    T0.CardCode           AS N'供應商代碼',
    T0.CardName           AS N'供應商名稱',
    T1.LineNum + 1        AS N'列號',
    T1.ItemCode           AS N'物料號碼',
    T1.Dscription         AS N'物料說明',
    T1.Quantity           AS N'訂購數量',
    T1.OpenQty            AS N'未交數量',
    T1.Price              AS N'單價',
    T1.LineTotal          AS N'未稅金額',
    T1.WhsCode            AS N'倉庫',
    T0.CANCELED           AS N'取消狀態'

FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry

WHERE T0.CardCode = '[%0]'
  AND ISNULL('[%1]', '') = ''


UNION ALL


/* 條件B：依物料查詢，業務夥伴條件必須空白 */

SELECT
    T0.DocNum,
    T0.DocDate,
    T0.DocDueDate,
    T0.CardCode,
    T0.CardName,
    T1.LineNum + 1,
    T1.ItemCode,
    T1.Dscription,
    T1.Quantity,
    T1.OpenQty,
    T1.Price,
    T1.LineTotal,
    T1.WhsCode,
    T0.CANCELED

FROM OPOR T0
INNER JOIN POR1 T1
    ON T0.DocEntry = T1.DocEntry

WHERE T1.ItemCode = '[%1]'
  AND ISNULL('[%0]', '') = ''

ORDER BY
    N'過帳日期' DESC,
    N'採購單號' DESC,
    N'列號'
```

輸入規則：

- 依供應商查詢：
  - `[%0]` 輸入完整的 `CardCode`
  - `[%1]` 必須留空

- 依物料查詢：
  - `[%0]` 必須留空
  - `[%1]` 輸入完整的 `ItemCode`

如果空白參數實際上會被 FMS 傳入空格，改用這個版本的空白判斷：

```sql
LTRIM(RTRIM(ISNULL('[%1]', ''))) = ''
```

以及：

```sql
LTRIM(RTRIM(ISNULL('[%0]', ''))) = ''
```

也就是第一個 `WHERE` 攓成：

```sql
WHERE T0.CardCode = LTRIM(RTRIM('[%0]'))
  AND LTRIM(RTRIM(ISNULL('[%1]', ''))) = ''
```

第二個改成：

```sql
WHERE T1.ItemCode = LTRIM(RTRIM('[%1]'))
  AND LTRIM(RTRIM(ISNULL('[%0]', ''))) = ''
```

如果這份仍然沒有資料，問題就不是 `WHERE` 邏輯，而是目前執行環境沒有把 `[%0]`、`[%1]` 替換成輸入值；這在真正的 FMS 或後端排程 `OBSJ` 中很常見，因為這兩種執行方式不能使用互動式參數。

## S061-Q012｜我可不可以 在ssms 存 這隻查訊報表的邏輯然後我再fms 呼叫這隻存取程序

日期：2026-08-10

**你的提問**

我可不可以 在ssms 存 這隻查訊報表的邏輯然後我再fms 呼叫這隻存取程序

**當時回答**

可以把查詢邏輯存進 SSMS，但如果要由 SAP B1 原生 FMS 呼叫，我更建議使用「資料表值函數（Table-Valued Function）」而不是預存程序。因為 FMS 本質上是用查詢結果回填欄位，`SELECT FROM 函數` 通常比 `EXEC 預存程序` 穩定。

## 方案一：建立資料表值函數

先在 SSMS 選擇正確的 SAP 公司資料庫，再執行：

```sql
CREATE OR ALTER FUNCTION dbo.Z_FN_OPOR_SEARCH
(
    @CardCode NVARCHAR(15),
    @ItemCode NVARCHAR(50),
    @Canceled NVARCHAR(1)
)
RETURNS TABLE
AS
RETURN
(
    SELECT
        T0.DocEntry,
        T0.DocNum,
        T0.DocDate,
        T0.DocDueDate,
        T0.CardCode,
        T0.CardName,
        T1.LineNum,
        T1.ItemCode,
        T1.Dscription,
        T1.Quantity,
        T1.OpenQty,
        T1.Price,
        T1.LineTotal,
        T1.WhsCode,
        T0.CANCELED,
        T0.DocStatus
    FROM OPOR T0
    INNER JOIN POR1 T1
        ON T0.DocEntry = T1.DocEntry
    WHERE
        (
            /* 條件A：供應商有值、物料空白 */
            (
                NULLIF(LTRIM(RTRIM(@CardCode)), '') IS NOT NULL
                AND NULLIF(LTRIM(RTRIM(@ItemCode)), '') IS NULL
                AND T0.CardCode = LTRIM(RTRIM(@CardCode))
            )

            OR

            /* 條件B：物料有值、供應商空白 */
            (
                NULLIF(LTRIM(RTRIM(@ItemCode)), '') IS NOT NULL
                AND NULLIF(LTRIM(RTRIM(@CardCode)), '') IS NULL
                AND T1.ItemCode = LTRIM(RTRIM(@ItemCode))
            )
        )
        AND
        (
            NULLIF(LTRIM(RTRIM(@Canceled)), '') IS NULL
            OR T0.CANCELED = UPPER(LTRIM(RTRIM(@Canceled)))
        )
);
```

在 SSMS 先測試供應商：

```sql
SELECT *
FROM dbo.Z_FN_OPOR_SEARCH
(
    N'供應商代碼',
    N'',
    N''
)
ORDER BY DocDate DESC, DocNum DESC, LineNum
```

測試物料：

```sql
SELECT *
FROM dbo.Z_FN_OPOR_SEARCH
(
    N'',
    N'物料號碼',
    N''
)
ORDER BY DocDate DESC, DocNum DESC, LineNum
```

務必用實際的 `CardCode` 與 `ItemCode` 取代範例文字。如果 SSMS 測試有資料，就代表核心查詢邏輯正確。

## 在查詢管理員呼叫

```sql
SELECT
    DocNum                         AS N'採購單號',
    DocDate                        AS N'過帳日期',
    DocDueDate                     AS N'交貨日期',
    CardCode                       AS N'供應商代碼',
    CardName                       AS N'供應商名稱',
    LineNum + 1                    AS N'列號',
    ItemCode                       AS N'物料號碼',
    Dscription                     AS N'物料說明',
    Quantity                       AS N'訂購數量',
    OpenQty                        AS N'未交數量',
    Price                          AS N'單價',
    LineTotal                      AS N'未稅金額',
    WhsCode                        AS N'倉庫',
    CANCELED                       AS N'取消狀態'
FROM dbo.Z_FN_OPOR_SEARCH
(
    '[%0]',
    '[%1]',
    '[%2]'
)
ORDER BY DocDate DESC, DocNum DESC, LineNum
```

參數：

- `[%0]`：供應商代碼
- `[%1]`：物料號碼
- `[%2]`：`N`、`Y`、`C`，留空代表全部

`[%0]` 和 `[%1]` 只能擇一填寫。

## 如果是真正的 FMS

原生 FMS 不適合顯示這種多欄、多筆報表。它主要是把查詢結果帶回目前畫面的一個欄位；SAP 官方也將格式化搜尋描述為把預先定義搜尋取得的值指派到欄位。[SAP Formatted Searches 說明](https://help.sap.com/doc/089315d8d0f8475a9fc84fb919b501a3/10.0/en-US/SDKHelp/SAPbobsCOM~FormattedSearches.html)

若只是要回傳目前供應商最近一張採購單號，可以這樣呼叫函數：

```sql
SELECT TOP 1
    DocNum
FROM dbo.Z_FN_OPOR_SEARCH
(
    $[$4.0.0],
    '',
    ''
)
ORDER BY DocDate DESC, DocNum DESC
```

如果需要多筆報表，應由「查詢管理員」執行，不是綁在單一欄位的 FMS。

        T1.ItemCode                       AS N'物料號碼',
        T1.Dscription                     AS N'物料說明',
        T1.Quantity                       AS N'訂購數量',
        T1.OpenQty                        AS N'未交數量',
        T1.Price                          AS N'單價',
        T1.LineTotal                      AS N'未稅金額',

    INNER JOIN POR1 T1

## S061-Q017｜1). [Microsoft][ODBC Driver 18 for SQL Server][SQL Server]Must specify table to select fro…

**你的提問**

找到問題了：SAP B1 在預先解析 `DECLARE/SET` 時，註解式的 `/* SELECT ... */` 在你目前環境沒有被正確識別，所以 SQL Server 最後收到不完整的 `SELECT`。

改成真正執行的子查詢，不使用參數註解：

```sql
DECLARE @CardCode NVARCHAR(50)
DECLARE @ItemCode NVARCHAR(100)
DECLARE @Canceled NVARCHAR(10)

SET @CardCode =
(
    SELECT MIN(T0.CardCode)
    FROM OCRD T0
    WHERE T0.CardCode = '[%0]'
)

SET @ItemCode =
(
    SELECT MIN(T0.ItemCode)
    FROM OITM T0
    WHERE T0.ItemCode = '[%1]'
)

SET @Canceled =
(
    SELECT MIN(T0.CANCELED)
    FROM OPOR T0
    WHERE T0.CANCELED = '[%2]'
)

EXECUTE [_CmSp_OPOR_Search]
    @CardCode,
    @ItemCode,
    @Canceled
```

這種寫法的效果是：

- `[%0]` 有正確供應商代碼：`@CardCode` 取得該代碼。

- `[%1]` 空白：`@ItemCode` 自動變成 `NULL`。
- `[%2]` 空白：`@Canceled` 自動變成 `NULL`。

DECLARE @CardCode NVARCHAR(50)

DECLARE @Canceled NVARCHAR(10)

SET @CardCode=(SELECT MIN(CardCode) FROM OCRD WHERE CardCode='[%0]')
SET @ItemCode=(SELECT MIN(ItemCode) FROM OITM WHERE ItemCode='[%1]')
SET @Canceled=(SELECT MIN(CANCELED) FROM OPOR WHERE CANCELED='[%2]')

EXECUTE [_CmSp_OPOR_Search] @CardCode, @ItemCode, @Canceled
```

請輸入完整代碼：

- `[%0]` 必須是 `OCRD.CardCode`，不是供應商名稱。
- `[%1]` 必須是 `OITM.ItemCode`，不是物料說明。
- `[%2]` 輸入 `N`、`Y` 或 `C`。

這是針對 `Must specify table to select from` 常用的 SAP B1 SQL Server處理方式：讓每個參數都來自一個真正、完整且有 `FROM` 的子查詢。

## S061-Q020｜沒有取消狀態 我的取消狀態 可以直接寫進去 我只找未結單據

日期：2026-08-10

**你的提問**

沒有取消狀態 我的取消狀態 可以直接寫進去 我只找未結單據

**當時回答**

了解，不需要「取消狀態」參數，直接固定只查：

```sql
T0.CANCELED = 'N'
AND T0.DocStatus = 'O'
```

也就是「未取消、未結案」的採購訂單。

## SSMS：Stored Procedure

```sql
CREATE OR ALTER PROCEDURE [_CmSp_OPOR_Search]
    @CardCode NVARCHAR(50),
    @ItemCode NVARCHAR(100)
AS
BEGIN
    SET NOCOUNT ON;

    /* 空字串轉成 NULL */
    SET @CardCode = NULLIF(LTRIM(RTRIM(@CardCode)), '');
    SET @ItemCode = NULLIF(LTRIM(RTRIM(@ItemCode)), '');

    SELECT
        T0.DocEntry                       AS N'內部號碼',
        T0.DocNum                         AS N'採購單號',
        T0.DocDate                        AS N'過帳日期',
        T0.DocDueDate                     AS N'交貨日期',
        T0.CardCode                       AS N'供應商代碼',
        T0.CardName                       AS N'供應商名稱',
        T1.LineNum + 1                    AS N'列號',
        T1.ItemCode                       AS N'物料號碼',
        T1.Dscription                     AS N'物料說明',
        T1.Quantity                       AS N'訂購數量',
        T1.OpenQty                        AS N'未交數量',
        T1.Price                          AS N'單價',
        T1.LineTotal                      AS N'未稅金額',
        T1.WhsCode                        AS N'倉庫',

        CASE T1.LineStatus
            WHEN 'O' THEN N'未結'
            WHEN 'C' THEN N'已結'
            ELSE T1.LineStatus
        END                               AS N'明細狀態'

    FROM OPOR T0
    INNER JOIN POR1 T1
        ON T0.DocEntry = T1.DocEntry

    WHERE
        /* 固定只找未取消單據 */
        T0.CANCELED = 'N'

        /* 固定只找未結採購訂單 */
        AND T0.DocStatus = 'O'

        /* 供應商條件；空白時不篩選 */
        AND (
            @CardCode IS NULL
            OR T0.CardCode = @CardCode
        )

        /* 物料條件；空白時不篩選 */
        AND (
            @ItemCode IS NULL
            OR T1.ItemCode = @ItemCode
        )

    ORDER BY
        T0.DocDate DESC,
        T0.DocNum DESC,
        T1.LineNum;
END
```

## SAP B1 呼叫查詢

這次不要使用註解式 `/* SELECT 1... */`，改用完整子查詢，避免再次出現 `Must specify table to select from`：

```sql
DECLARE @CardCode NVARCHAR(50)
DECLARE @ItemCode NVARCHAR(100)

SET @CardCode =
(
    SELECT MIN(T0.CardCode)
    FROM OCRD T0
    WHERE T0.CardCode = '[%0]'
)

SET @ItemCode =
(
    SELECT MIN(T0.ItemCode)
    FROM OITM T0
    WHERE T0.ItemCode = '[%1]'
)

EXECUTE [_CmSp_OPOR_Search]
    @CardCode,
    @ItemCode
```

篩選邏輯：

| `[%0]` 供應商 | `[%1]` 物料 | 結果 |
|---|---|---|
| 有值 | 空白 | 該供應商的未結採購訂單 |
| 空白 | 有值 | 該物料的未結採購訂單 |
| 有值 | 有值 | 該供應商且包含該物料 |
| 空白 | 空白 | 全部未結採購訂單 |

如果你只想顯示「未結明細列」，在 Stored Procedure 的 `WHERE` 再加：

```sql
AND T1.LineStatus = 'O'
```

這樣已結案的明細列也會排除，只留下仍有未交數量的採購明細。
