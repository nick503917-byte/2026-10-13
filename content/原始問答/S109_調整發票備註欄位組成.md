如果我想改成 組成分別為  'AR發票 -'+ T0.CardCode + ' ' + T0.DocDate + T0.DocNum  這樣可以嗎?

**當時回答**

可以，但 `DocDate` 是日期、`DocNum` 通常是數字，不能直接用 `+` 串接，需先轉成文字。

建議統一改成：

```sql
'AR發票 -' + T0.CardCode
+ ' ' + CONVERT(varchar(10), T0.DocDate, 111)
+ ' ' + CONVERT(varchar(20), T0.DocNum)
```

結果例如：

```text
AR發票 -C00001 2026/08/24 123456
```

套用在更新語句中，例如：

```sql
UPDATE T0
SET T0.JrnlMemo =
    'AR發票 -' + T0.CardCode
    + ' ' + CONVERT(varchar(10), T0.DocDate, 111)
    + ' ' + CONVERT(varchar(20), T0.DocNum)
FROM OINV T0
WHERE T0.DocEntry = @list_of_cols_val_tab_del
  AND REPLACE(ISNULL(T0.U_IN_BSINV, ''), '*', '') <> ''
```

另外兩個欄位也使用相同組合：

```sql
UPDATE T1
SET T1.Memo =
    'AR發票 -' + T0.CardCode
    + ' ' + CONVERT(varchar(10), T0.DocDate, 111)
    + ' ' + CONVERT(varchar(20), T0.DocNum)
FROM OINV T0
INNER JOIN OJDT T1
    ON T0.DocNum = T1.BaseRef
WHERE T0.DocEntry = @list_of_cols_val_tab_del
  AND T1.TransType = '13'
  AND REPLACE(ISNULL(T0.U_IN_BSINV, ''), '*', '') <> '';

UPDATE T2
SET T2.LineMemo =
    'AR發票 -' + T0.CardCode
    + ' ' + CONVERT(varchar(10), T0.DocDate, 111)
    + ' ' + CONVERT(varchar(20), T0.DocNum)
FROM OINV T0
INNER JOIN OJDT T1
    ON T0.DocNum = T1.BaseRef
INNER JOIN JDT1 T2
    ON T1.TransId = T2.TransId
WHERE T0.DocEntry = @list_of_cols_val_tab_del
  AND T1.TransType = '13'
  AND REPLACE(ISNULL(T0.U_IN_BSINV, ''), '*', '') <> '';
```

若想顯示成 `20260824`，日期部分可改為：

```sql
CONVERT(varchar(8), T0.DocDate, 112)
```

也要留意 `OJDT.Memo`、`JDT1.LineMemo` 的欄位長度，超過時 SQL Server 可能出現資料截斷錯誤。

## S109-Q002｜幫我寫完整

日期：2026-08-24

**當時回答**

```sql
-- 發票備註欄位處理
-- 20260112 Tommy 重新啟用
-- 20260316 Tommy 增加 OJDT.TransType 對應
-- 20260623 Tommy 增加貸項通知單
-- 銷項－AR 發票

IF @object_type IN ('13')
   AND @transaction_type IN ('U', 'A')
BEGIN

    -- 更新 AR 發票備註
    UPDATE T0
    SET T0.JrnlMemo =
          'AR發票 -'
        + ISNULL(T0.CardCode, '')
        + ' '
        + CONVERT(VARCHAR(8), T0.DocDate, 112)
        + ' '
        + CONVERT(VARCHAR(20), T0.DocNum)
    FROM OINV T0
    WHERE T0.DocEntry = @list_of_cols_val_tab_del
      AND REPLACE(ISNULL(T0.U_IN_BSINV, ''), '*', '') <> '';


    -- 更新傳票表頭備註
    UPDATE T1
    SET T1.Memo =
          'AR發票 -'
        + ISNULL(T0.CardCode, '')
        + ' '
        + CONVERT(VARCHAR(8), T0.DocDate, 112)
        + ' '
        + CONVERT(VARCHAR(20), T0.DocNum)
    FROM OINV T0
    INNER JOIN OJDT T1
        ON T0.DocNum = T1.BaseRef
       AND T1.TransType = '13'
    WHERE T0.DocEntry = @list_of_cols_val_tab_del
      AND REPLACE(ISNULL(T0.U_IN_BSINV, ''), '*', '') <> '';


    -- 更新傳票明細備註

    SET T2.LineMemo =
          'AR發票 -'
        + ISNULL(T0.CardCode, '')
        + ' '
        + CONVERT(VARCHAR(8), T0.DocDate, 112)
        + ' '
        + CONVERT(VARCHAR(20), T0.DocNum)
    FROM OINV T0
    INNER JOIN OJDT T1
        ON T0.DocNum = T1.BaseRef
       AND T1.TransType = '13'
    INNER JOIN JDT1 T2
        ON T1.TransId = T2.TransId
    WHERE T0.DocEntry = @list_of_cols_val_tab_del
      AND REPLACE(ISNULL(T0.U_IN_BSINV, ''), '*', '') <> '';

END;
```

產生的內容格式會是：

