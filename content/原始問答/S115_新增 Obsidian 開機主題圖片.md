## S115-Q020｜我要怎麼改

日期：2026-08-28

**你的提問**

我要怎麼改

**當時回答**

最簡單的方法是另外建立一個 CSS 片段，避免改到目前的背景設定。

1. 開啟 Obsidian「設定 → 外觀」
2. 找到「CSS 片段」
3. 點資料夾圖示
4. 建立檔案 `heading-colors.css`
5. 貼上以下內容：

```css
/* H1 大標題 */
.markdown-rendered h1,
.cm-header-1 {
  color: #ff66cc !important;
}

/* H2 標題 */
.markdown-rendered h2,
.cm-header-2 {
  color: #66ccff !important;
}

/* H3 標題 */
.markdown-rendered h3,
.cm-header-3 {
  color: #ffd166 !important;
}
```

儲存後回到 Obsidian，在「CSS 片段」按重新整理，開啟 `heading-colors`。

只想修改大標題 H1，就只保留第一段。`#ff66cc` 是粉紅色，可替換成其他色碼，例如：

- 金色：`#ffd166`
- 淺藍：`#66ccff`
- 紫色：`#c792ea`
- 綠色：`#7bd88f`
- 白色：`#ffffff`
