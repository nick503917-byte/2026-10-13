| 主題 | 閱讀時需注意 |
|---|---|
| 庫存調撥參考文件 | 早期回答混用了「參考文件」與「上傳附件」；不可視為同一功能。早期 RefDocNum／DocNum JOIN 也不能套用所有主從關係。 |
| 商品結清科目 | 不同聊天把它解釋成暫估過渡或結清差異；需要依英文欄位及公司科目設定查核。 |
| 銷貨退回分錄 | 後續已修正科目說法；應回看最新上下文與科目決定。 |
| Series／Object Type | 前期曾混淆；後續明確區分編號系列與單據物件類型。 |
| RAWITEMCREA 特殊字元 | 實際需檢核 Code；前期 U_ItemCode／DocEntry 假設並不符合該案例。 |
| 越南價格與 FMS | 文字格式與數值欄位需分開處理，不能把所有小數點／逗號一律替換。 |
| DTW 翻譯 LineNum | 原回答有「第一筆填 0」與「新增先留白」兩種說法；新增／更新需按版本範本確認，不能直接拼成一套匯入檔。 |
| 六位小數／Excel 匯出 | 計算精度、顯示格式、文字結果是三件事。 |
| 歷史庫存估價 | 部分 SQL 採目前平均成本估算歷史結存，非歷史實際成本。 |
| 固定資產重估 | 有未確認系統就給通用操作路徑的內容，不當作 SAP B1 已核實路徑。 |
| 原始 SQL | 包含 UPDATE 與 ALTER 等歷史程式碼；本次未執行，也不代表每段都已通過測試或正式部署。 |
| 時效資料 | 方案額度、產品價格、補助、法規與旅遊活動只代表當時回答。 |
